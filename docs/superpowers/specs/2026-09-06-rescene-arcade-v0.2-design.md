# 리센느스토리 v0.2 — 아케이드 개정 설계

작성 2026-09-06 · v0.1(`2026-09-04-rescene-story-design.md`)을 대체하는 부분만 적는다. 서사 연표·유행어 목록·출처·에셋 원칙은 v0.1 §3·§5·§9·§14를 그대로 참조한다.

## 0. 왜 바꾸는가

v0.1은 메이플스토리식 RPG(레벨·인벤토리·퀘스트·저장 슬롯)였다. 수직 슬라이스(장면 0~1)를 만들어 보니 메뉴와 숫자가 서사보다 앞에 섰다. v0.2는 **옛날 오락실 횡스크롤 액션**으로 구조를 바꾼다. 한 판 10~15분, 버튼 3개, 화면에 숫자 최소. 리센느의 연표와 유행어는 그대로 게임의 뼈대다.

| 항목 | v0.1 | v0.2 |
|---|---|---|
| 장르 | 횡스크롤 액션 RPG | 횡스크롤 아케이드 액션(스테이지 진행형) |
| 한 판 | 3~4시간, 저장 슬롯 3개 | 10~15분, 목숨 3 + 컨티뉴 1, 하이스코어 |
| 성장 | 레벨·경험치·SP·장비·음식 | 없음. 한 판 안에서 유행어 카드로 일시 강화 |
| 조작 | 이동·점프·공격·스킬 2·회복 | 이동·점프·공격(3연타)·유행어 필살기 |
| 서사 | 허브 맵·퀘스트·대화 트리 | 스테이지 5개 + 사이사이 3줄 인트로 카드 + 엔딩 롤 |
| 음성 | 없음 | 멤버별 합성 블립(모든 대사·유행어) + 권리 확보 음성 파일 슬롯 |

## 1. 설계 원칙 (v0.1 §2에 추가)

6. **한 판은 짧고 끝이 있다.** 스테이지 5개를 잇달아 깨면 엔딩. 실패해도 15분 안에 다시 시작한다.
7. **버튼 3개, 숫자는 점수와 하트뿐.** 데미지 숫자·레벨·능력치 창을 화면에 두지 않는다.
8. **리센느는 원본을 복제하지 않고 스타일화한다.** 실제 음성·영상·얼굴을 쓰지 않는다. 음성은 합성 블립이 기본이고, 음성 파일 슬롯은 권리를 확보한 파일에만 쓴다(§9.3).
9. **데이터 주도 유지.** 스테이지·웨이브·보스·유행어·음색은 전부 데이터. 새 컴백은 스테이지 파일 하나 추가로 붙는다.

## 2. 한 판(Run)의 흐름

```
타이틀(하이스코어) → 캐릭터 선택 → [스테이지 인트로 카드 → 스테이지 → 결과] × 5 → 엔딩 롤 → 이니셜 입력 → 타이틀
                                      └ 사망: 목숨 -1 → 구간 처음부터 / 목숨 0: 컨티뉴?(10초) → 예: 점수 0, 스테이지 유지 / 아니오: 게임 오버 → 이니셜 입력
```

- **목숨 3개, 컨티뉴 1회.** 컨티뉴하면 점수가 0이 되고 현재 스테이지 첫 구간에서 다시 시작한다.
- **체력은 하트 5칸.** 잡몹 접촉·탄 1칸, 보스 2칸. 하트 아이템은 1칸 회복. 스테이지를 깨면 5칸으로 회복.
- **스테이지 셀렉트.** 한 번 깬 스테이지는 타이틀에서 골라 시작할 수 있다(점수는 0에서, 하이스코어 등록 가능). 처음 여는 사람은 스테이지 1부터.
- **결과 화면(스테이지 클리어)**: 처치 점수 · 콤보 최대 · 노히트 보스 보너스 · 남은 목숨 보너스 · 시간 보너스를 순서대로 올려 합산(3초). Enter로 넘김.

## 3. 스테이지 5개

v0.1 장면 1~6을 5개로 묶는다(장면 3·4를 하나로). 각 스테이지는 맵 1개(가로 60~120 타일) + 구간 4~6개, 마지막 구간이 보스. 목표 시간 2~3분.

| # | 스테이지 | 실제 시기 (v0.1 §3) | 맵(구간 순서) | 잡몹 | 보스 |
|---|---|---|---|---|---|
| 1 | 연습생 | 2022~2024.02 | 더뮤즈 연습실(야간) → 편의점 골목 → 옥상 → 월말평가장 | 졸음 슬라임 · 근육통 버섯 · 박자이탈 메트로놈 · 자기의심 그림자 | **월말평가 심사위원단** (보컬/댄스/랩 3페이즈, 현재 구현 유지) |
| 2 | 데뷔 | 2024.02.07~03.26 | 티저 촬영 스튜디오 → 방송국 복도 → 대기실 → UhUh 무대 | 긴장 떨림 · 인이어 노이즈 · 무반응 관객 | **첫 카메라** — 렌즈가 열린 동안만 피해를 입는다. 3연타 콤보 3번을 성공하면 렌즈가 열림 |

- 인트로 카드는 스테이지마다 3줄, v0.1 §3 표의 사실만 쓴다(날짜 포함). 엔딩 롤은 데뷔 841일 첫 1위까지의 연표를 한 줄씩 올린다.
- 잡몹은 전부 감정·장애물의 의인화다. 실존 타 그룹·개인·회사는 등장하지 않는다(더뮤즈는 소속사 이름이므로 유지).
- **엘리트**: 잡몹 중 일부를 큰 크기·다른 색으로 스폰(`elite: true`). 처치하면 유행어 카드를 반드시 떨군다. 스테이지마다 2~3마리.
- **응원 NPC**: 멤버 NPC 4인이 구간 사이 배경에 서서 한 마디(블립) 한다. 상호작용 없음. 공격 판정 없음.

### 구간(section) 규칙

- 구간은 맵의 `lock` 오브젝트(x 좌표)로 끝난다. 플레이어가 잠금선을 넘으면 카메라가 잠기고 그 구간의 웨이브가 시작된다.
- 웨이브는 `{ spawn, enemy, count, intervalMs, elite? }` 목록이다. `spawn`은 맵의 스폰 오브젝트 이름. 모든 웨이브의 적이 죽으면 "GO →" 화살표가 1.5초 깜빡이고 카메라가 풀린다.
- 보스 구간은 `boss: { id, spawn }` 하나. 보스가 죽으면 스테이지 클리어.
- 구간 안에서 죽으면 그 구간의 잠금선에서 다시 시작하고 웨이브는 처음부터.
- 스테이지 타이머(3분)는 시간 보너스 계산에만 쓰고 시간이 다 돼도 죽지 않는다.

## 4. 조작·전투

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| Space | 점프(2단 점프), ↓+Space 발판 내려가기 |
| ↑ / ↓ | 사다리 오르내리기 |
| A | 공격. 0.6초 안에 연타하면 1타→2타→3타 **체인**. 3타는 배율 1.6, 넉백 2배 (점수의 '콤보'는 §7의 연속 처치를 뜻한다) |
| S | 유행어 필살기(게이지 100%일 때) |
| M | 음소거 토글 |
| Enter | 확인 / 일시정지 |

- **멤버 능력치는 셋.** 공격력(atk)·속도(spd)·점프(jump). 데미지 = atk × 배율. 방어·치명타·행운·기력·레벨은 없다.
- **원거리 멤버**(리브·미나미·메이)의 A는 투사체, **근접 멤버**(원이·제나)는 판정 상자. 현재 `SkillDef`의 `*_basic` 정의를 그대로 쓴다.
- **무적 시간**: 피격 후 1초 점멸. 필살기 연출 중 무적.
- **적 AI**는 현재 patrol/chase/boss를 유지. `score`만 추가.

|---|---|---|---|---|
| 원이 | 10 | 5 | 5 | 근접(마이크 스탠드) |
| 리브 | 8 | 6 | 5 | 원거리(음파) |
| 미나미 | 9 | 6 | 6 | 원거리(먹물) |
| 메이 | 7 | 7 | 6 | 원거리(스티커) |

## 5. 리센느 게이지와 유행어 필살기

- 게이지 0~100. 타격 +4, 처치 +12, 엘리트 처치 +30, 피격 시 변화 없음. 스테이지 시작 시 0.
- 100%가 되면 게이지가 반짝이고 짧은 알림음. S로 발동. 발동 시 게이지 0.
- **연출(1.2초, 전부 무적·적 정지)**: 0.4초 정지 → 멤버 컷인(스프라이트 4배 확대가 오른쪽에서 슬라이드) → 큰 자막(유행어, 화면 중앙, 흔들림) + 음성(파일 또는 블립) → 효과 적용 → 정지 해제.
- 효과는 현재 시그니처 스킬 정의를 재사용하되 강화한다.

| 멤버 | 유행어 | 효과(스킬 데이터) |
|---|---|---|
| 원이 | 우이! | 화면 안 모든 적에게 atk×2.0 + 넉백 300. 이후 8초 atk +20% |
| 리브 | 고음 안정 → 자막 "너도? 나도!" | 화면을 가로지르는 관통 음파 atk×2.5, 맞은 적 1초 경직 |
| 미나미 | 일필휘지 → 자막 "거제, 야호~!" | 화면 가로 베기 atk×3.0 |
| 메이 | 쫑알쫑알 → 자막 "기회는 그립감이 좋다" | 화면 안 모든 적에게 5틱 지속 피해(틱당 atk×0.5), 방어 디버프 없음 |
| 제나 | 까엉턴 → 자막 "아뉘이이이!" | 주변 반경 120px atk×3.0 + 넉백 250 |

> 필살기 이름(스킬)과 자막(유행어)이 다른 멤버는 자막이 우선 표시되고 스킬 이름은 결과 화면 로그에만 남는다.

## 6. 유행어 카드 (리센느 사전)

- **획득**: 엘리트 처치(확정) · 구간 클리어 보상 상자(30%) · 보스 처치(확정 1장). 카드가 바닥에 떨어지고 닿으면 획득. 획득 순간 카드 앞면(문장)이 1.5초 크게 떠오르고 그 멤버의 블립이 문장을 읽는다.
- **한 판 강화**: 최대 3장 보유. 4장째를 얻으면 가장 오래된 것이 도감으로만 남고 효과가 빠진다. 효과는 v0.1 패시브를 재해석한다.

| 패시브 키 | 효과 |
|---|---|
| atk | 공격력 +2 |
| spd | 속도 +1 |
| jump | 점프 +1 |
| gauge | 게이지 충전 +25% |
| heart | 하트 최대 +1(즉시 1칸 회복) |
| combo | 콤보 유지 시간 2초 → 3초 |
| score | 점수 +10% |

- **도감(영구)**: 획득한 카드 id를 저장. 타이틀의 "리센느 사전"에서 앞면(문장)·뒷면(출처·해설)을 넘겨 본다. 도감에서 카드를 고르면 그 멤버 블립이 읽어 준다.
- 카드 29장 목록과 표기는 v0.1 §5. 현재 데이터 11장(오이쉬에~ 포함)에서 시작해 스테이지별 드랍 테이블로 배분한다.

## 7. 점수·하이스코어

| 항목 | 점수 |
|---|---|
| 잡몹 처치 | 적별 100~300 (`EnemyDef.score`) |
| 엘리트 처치 | 500 |
| 보스 처치 | 3000 |
| 콤보 배수 | 2초 안 연속 처치 5회부터 ×2, 10회부터 ×3 (카드 `combo`는 창을 3초로) |
| 보스 노히트 | +2000 |
| 스테이지 클리어 | 남은 목숨 × 1000 + 남은 초 × 10 |

- 하이스코어는 상위 10개 `{ initials, score, member, stageReached, date }`. 게임 오버·엔딩 뒤 10위 안이면 이니셜 3글자 입력(← → 글자, Enter 확정; 영문 대문자·숫자·`.`).
- 컨티뉴하면 점수 0. 스테이지 셀렉트로 시작한 판도 등록된다(`stageReached`로 구분 표시).

## 8. HUD와 화면

- 왼쪽 위: 멤버 얼굴(스프라이트 머리 부분 2배) + 하트 5칸 + 목숨 아이콘 ×n.
- 오른쪽 위: 점수(7자리 0 채움) + 하이스코어 1위.
- 아래 가운데: 리센느 게이지 바(100%면 무지개 점멸 + "S!" 표시).
- 가운데 위: 콤보 카운터(처치 시 튀어오름), "GO →", "NO HIT!", 보스 이름.
- 보스 구간: 화면 아래 보스 체력 바(페이즈 구분선).
- 폰트·색은 현재 HUD(`textStyles.ts`)를 유지. 데미지 숫자 팝업은 삭제하고 타격 스파크만 남긴다.

## 9. 오디오

### 9.1 음성 블립 엔진 (`src/systems/voice.ts`, 순수 TS)

- 입력: 문장, 멤버 음색 프로필. 출력: `VoiceNote[] = { at: number; durationMs: number; freq: number; gain: number; wave: 'square' | 'triangle' | 'sawtooth' | 'pulse' }`.
- 문장을 문자 단위로 훑는다. 한글 음절(U+AC00~U+D7A3)은 초성·중성·종성으로 분해한다.
  - 음높이: 프로필 `baseHz` × 2^(semitone/12). semitone = (중성 index % 7) − 3 + (초성 index % 3). 종성이 있으면 −1.
  - 길이: 프로필 `syllableMs`. 종성이 있으면 +20ms.
  - 공백·쉼표: 80ms 쉼. `!`: 직전 노트 gain ×1.3. `?`: 직전 노트 +4 semitone. `~`: 직전 노트 길이 ×2, 다음 노트와 이어짐(슬라이드 표시 `slideTo`).
  - 한글이 아닌 글자(영문·숫자)는 semitone 0, 길이 `syllableMs`.
- 결정론적이다. 같은 문장 + 같은 프로필 = 같은 노트 배열. 최대 24노트(긴 문장은 잘라 읽는다).

| 멤버 | baseHz | syllableMs | wave | 비고 |
|---|---|---|---|---|
| 원이 | 220 | 85 | square | 낮고 단단 |
| 리브 | 330 | 80 | triangle | 맑음 |
| 미나미 | 392 | 65 | pulse | 높고 빠름 |
| 메이 | 349 | 70 | pulse | 톡톡 튐, 비브라토 |
| 제나 | 262 | 60 | square | 짧고 낮음 |
| NPC(공통) | 196 | 90 | sawtooth | 역할 NPC·심사위원 |

### 9.2 재생 (`src/audio/AudioBus.ts`)

- Web Audio API 직접 사용(Phaser Sound는 파일 재생에만). `AudioContext`는 첫 키 입력에서 `resume()`.
- `speak(notes)`: 노트마다 OscillatorNode + GainNode(어택 5ms, 릴리즈 20ms). 이미 말하는 중이면 끊고 새로 시작.
- `sfx(name)`: 절차 합성 효과음 — `hit`, `hit3`(3타), `jump`, `kill`, `elite`, `gauge`(완충), `super`, `hurt`, `card`, `go`, `heart`, `boss_phase`, `clear`, `gameover`, `menu`. 각각 주파수 스윕·노이즈·짧은 아르페지오로 정의된 데이터(`src/audio/sfxData.ts`).
- `bgm(id)`: 패턴 시퀀서. 4채널(베이스·리드·화음·노이즈 드럼), 16분음표 스텝 데이터. 곡 3개: `title`, `stage`, `boss`. 원곡 인용 없음. 스테이지 데이터의 `bgm`으로 선택.
- 마스터 볼륨·음소거는 `localStorage`의 `settings.muted`.

### 9.3 음성 파일 슬롯

- 위치: `public/assets/voice/<memeId>.ogg`(또는 `.mp3`). 파일 이름이 유행어 카드 id다(예: `woni_ui.ogg`).
- `npm run voice`(`tools/build-voice-manifest.ts`)가 폴더를 훑어 `public/assets/voice/manifest.json`(`{ files: ["woni_ui.ogg", ...] }`)을 만든다. Preload는 manifest에 있는 파일만 로드한다(없는 파일을 요청하지 않으므로 404가 없다).
- 재생 규칙: 유행어(필살기·카드 획득·도감)는 파일이 있으면 파일, 없으면 블립. 대사·인트로 카드는 항상 블립.
- 파일은 권리를 확보한 것만 넣는다(소속사 제공·직접 녹음). 저장소에는 파일을 커밋하지 않고 `.gitignore`에 `public/assets/voice/*.ogg|mp3`를 둔다. manifest는 커밋한다(빈 목록).

## 10. 데이터 스키마 (zod, `src/data/schema.ts`)

```ts
MemberDef { id, name, role, hometown, color, atk, spd, jump, attack: 'melee'|'ranged',
            weapon, basicSkill, superSkill, superText /*자막 유행어*/, voice: VoiceProfile }
VoiceProfile { baseHz, syllableMs, wave, vibrato?: number }
EnemyDef { id, name, hp, atk, spd, score, ai: 'patrol'|'chase'|'boss', width, height, color,
           heartChance, eliteScale?: number /*엘리트 배율, 기본 1.5*/ }
BossDef extends EnemyDef { phases: { hpRatio, name }[], gimmick?: 'lens'|'silence'|'copycat'|'trophy' }
SkillDef { id, name, member, multiplier, effects[] }   // mpCost·cooldown·level 삭제
MemeDef  { id, member, text, origin, note, buff: { key: BuffKey, value } }
StageDef { id, index, name, era, map, intro: string[3], bgm, timerSec,
           sections: { lock: string /*맵 lock 오브젝트 이름*/, waves: WaveDef[], chest?: boolean, cheer?: { npc, text } }[],
           boss: { id, spawn }, cardPool: memeId[] }
```

- `validateAllData()`가 스테이지의 맵·스폰·lock·적·카드 id를 모두 검증한다. 맵 소스(`maps/*.txt`)의 `lock`·`spawn` 오브젝트와 교차 검증은 `tests/maps.test.ts`에 추가.
- v1 세이브(`rescene.save.*`)는 읽지 않고 지운다. 하이스코어 키는 `rescene.arcade`.

## 11. 아키텍처

### 11.1 씬

```
Boot → Preload → Title ──→ Select → StageIntro(Cutscene 재사용) → Stage (+Hud) ─┬→ Result → 다음 StageIntro
                     │                                                          ├→ Continue → Stage(구간 처음)
                     ├→ Codex(리센느 사전)                                       └→ GameOver → NameEntry → Title
                     └→ StageSelect                                     S5 클리어 → Ending → NameEntry → Title
```

- `StageScene`은 현재 `WorldScene`을 개편한다: 포탈·세이브포인트·NPC 상호작용·퀘스트 훅을 빼고 `SectionController`(카메라 잠금·웨이브 스폰·GO)를 더한다. `CombatController`는 콤보·게이지·필살기 연출을 맡고 아이템·경험치 처리를 뺀다.
- 필살기 연출은 `SuperCutscene`(오버레이 씬)이 아니라 `StageScene` 안의 `physics.pause()` + 타임라인으로 한다. 씬 큐 순서 문제(v0.1 교훈)를 피한다.

### 11.2 순수 시스템 (`src/systems`, Phaser 미의존)

| 모듈 | 책임 | 상태 |
|---|---|---|
| `run.ts` | `RunState { member, stageIndex, lives, hearts, maxHearts, score, gauge, cards[], continues, noHitBoss }`와 리듀서(`hit`, `kill`, `pickup`, `die`, `useContinue`, `stageClear`) | 신규 |
| `score.ts` | 콤보 창·배수, 클리어 보너스 계산 | 신규 |
| `waves.ts` | 구간 상태 머신(`idle → locked → spawning → cleared → open`), 스폰 예약 목록 | 신규 |
| `cards.ts` | 카드 보유(최대 3)·버프 합산·도감 갱신 | `memes.ts` 대체 |
| `highscore.ts` | 삽입·정렬·상위 10·직렬화 | `save.ts` 대체 |
| `voice.ts` | 문장 → 노트 배열 | 신규 |
| `movement.ts` | 유지 | 유지 |
| `combat.ts` | `damage(atk, multiplier)`로 단순화 | 축소 |
| `dialogue.ts` | 선형 컷신 텍스트만 | 축소 |
| 삭제 | `progression.ts`, `inventory.ts`, `quest.ts`, `questText.ts`, `npcInteraction.ts`, `skills.ts`(쿨다운·기력), `save.ts`(슬롯) | 삭제 |

`GameState`/`EventBus`는 `RunState`를 감싸는 얇은 래퍼로 남긴다(이벤트: `changed`, `gauge_full`, `combo`, `card`, `section`, `boss_phase`).

### 11.3 엔티티

- `Player`: 콤보 단계·게이지 신호·필살기 프레임 재생. 스탯은 `RunState`에서 읽는다.
- `Enemy`/`Boss`: 유지. `elite` 플래그면 `setScale(1.5)`·틴트·hp×3·확정 카드 드랍. 보스 기믹은 `Boss`의 서브클래스 4개(`LensBoss`, `SilenceBoss`, `CopycatBoss`, `TrophyBoss`).
- `DropItem`: 하트(멤버별 시그니처 음식 도트)·카드만.
- 삭제: `Npc` 상호작용(응원 NPC는 애니메이션만 있는 `CheerNpc`), `Portal`, `ScentSavePoint`.

## 13. 테스트 전략

- **Vitest(순수)**: `run`(하트·목숨·컨티뉴·게이지 경계), `score`(콤보 창·배수·보너스), `waves`(상태 전이·스폰 예약·전멸 판정), `cards`(3장 초과·버프 합산), `highscore`(정렬·10개·직렬화 왕복), `voice`(결정론·음절 수 = 노트 수·프로필별 차이·`~` 슬라이드·24노트 상한), 데이터 검증(스테이지 ↔ 맵 오브젝트 ↔ 적 id ↔ 카드 id), 스프라이트·맵·voice manifest 생성물 일치, `src/systems`·`src/core`·`src/audio/sfxData` no-phaser.
- **Playwright**: 부트 → 선택 → 인트로 → 스테이지 1 첫 구간에서 웨이브 전멸 → "GO →" 확인 → 콘솔 오류 0. 필살기 발동(게이지를 `window.__game`으로 채움) 1회.
- **수동 체크리스트**(`docs/playtest-checklist.md` 개정): 스테이지 5개 각 2분 안에 클리어 가능, 컨티뉴 흐름, 이니셜 입력, 음소거, 파일 슬롯에 임시 ogg를 넣었을 때 교체 재생.
