# 리센느스토리 v0.2 — 캐릭터 v2 부록 (초상화·3등신 스프라이트·시그니처 동작·말투)

작성 2026-09-06. v0.2 아케이드 설계(`2026-09-06-rescene-arcade-v0.2-design.md`) §4·§5·§9·§12를 보강한다. 사용자 피드백: "캐릭터가 너무 투박하고 리센느 멤버 특징이 안 산다." 살릴 특징 네 가지 — 얼굴·표정, 머리·의상 디테일, 시그니처 동작, 음성·말투.

원칙(유지): 실제 얼굴·사진·음성을 복제하지 않는다. "알아보게" 만드는 것은 머리 모양·시그니처 표정·동작·유행어·말버릇이다. 실명·닮은꼴 금지.

## 1. 초상화 (Portrait)

- **규격**: 64×64 도트, 1px 외곽선, 멤버당 3프레임 시트(`portrait_<member>.png`, 192×64): 0 기본 · 1 시그니처 · 2 피격.
- **합성 부품**(`tools/sprites/portraits.ts`): 얼굴형(피부·목·어깨) + 뒷머리 + 앞머리(5종: long/bob/wavy/short/twin, 스프라이트와 같은 이름·색) + 눈(기본·감음·윙크·반짝·찡그림) + 입(미소·크게 벌림·혀·오므림·볼 부풀림) + 볼터치 + 손·소품 오버레이 + 액세서리(제나 리본, 미나미 갸루 눈밑 하이라이트, 원이 귀걸이, 리브 초커, 메이 헤어클립).
- **시그니처 표정(프레임 1)**: 원이 "우이!" — 눈 꼭 감고 입 크게, 두 손 위로 · 리브 왕따봉 — 윙크 + 엄지 · 미나미 갸루 피스 — 브이 + 혀 · 메이 그립감 — 두 손 모으고 반짝 눈 · 제나 "아뉘" — 볼 부풀리고 눈썹 내림.
- **피격(프레임 2)**: 눈 `><`, 입 물결.
- **쓰는 곳**: 캐릭터 선택(3배 192px), 필살기 컷인(3배, 오른쪽에서 슬라이드 — 지금의 스프라이트 4배 확대를 대체), 결과 화면(승리 표정 = 시그니처), 엔딩, 카드 획득 자막 옆(1배), 컨티뉴 화면(피격).

## 2. 스프라이트 3등신

- **규격**: 32×64 도트(프레임 40×64, 아래 가운데 정렬 — 소품이 옆으로 튀어나올 여유 4px). 머리 0~23행(앞머리·옆머리·뒷머리 3층, 눈 2×2 + 하이라이트, 입, 볼터치), 목 24~25, 몸통 26~45, 다리 46~63.
- **물리 몸**: `PLAYER_BODY = { width: 24, height: 56, offsetX: 8, offsetY: 8 }`(프레임 좌표). 맵 세로 간격은 3행(96px) 이상이므로 통과 가능.
- **프레임 15장**(`src/core/spriteFrames.ts`가 원본):

| 인덱스 | 이름 | 내용 |
|---|---|---|
| 0,1 | idle | 대기(숨쉬기) |
| 2 | flourish | 대기 중 6초마다 1회 재생하는 개인기(멤버별: 원이 팔짱·끄덕, 리브 머리 넘기기, 미나미 피스, 메이 손 모으기, 제나 헤어핀 만지기) |
| 3~6 | walk | 걷기 |
| 7 | jump | 점프 |
| 8 / 9 / 10 | attack1 / attack2 / attack3 | 체인 1·2·3타(3타는 큰 휘두름·소품 앞으로) |
| 11 | hurt | 피격 |
| 12,13 | super | 필살기 포즈(멤버별: 우이! 두 팔 벌림 / 왕따봉 엄지 / 갸루 피스 / 그립감 손 모으기 / 까엉턴 회전) |
| 14 | win | 승리 포즈(결과 화면) |

- **의상 5벌**(스테이지별 교체, `StageDef.outfit`): `training` 연습복(S1) · `debut` Re:Scene(S2, 화이트 톱 + 블랙 스커트 + 보라 포인트) · `road` LOVE ATTACK 시기(S3, 데님 재킷 + 크롭탑) · `comeback` 역주행(S4, 캐주얼 후드 + 멤버 컬러 팬츠) · `pretty` Pretty Girl(S5, 파스텔 핑크 스커트 + 옐로 포인트). 시트 파일 `player_<member>.png`(= training, 기존 이름 유지) + `player_<member>_<outfit>.png`. 하의 실루엣은 바지/스커트/쇼츠 3종, 상의는 재킷 오버레이 유무.
- **멤버 디테일**(닮은꼴 아님, 스타일 표식): 원이 긴 생머리 + 귀걸이 + 마이크 스탠드 · 리브 단발 + 초커 + 핸드 마이크 · 미나미 웨이브 롱 + 갸루 하이라이트 + 붓 · 메이 짧은 단발 + 헤어클립 + 스티커 키링 · 제나 트윈테일 + 리본(신라공주).
- NPC 9종도 같은 32×64 템플릿으로 재생성(멤버 NPC는 멤버 외형 재사용, 대기 2프레임 유지).

## 3. 시그니처 동작 (게임 연결)

- 체인 1/2/3타 → attack1/2/3 프레임. 3타는 히트스톱 60ms.
- 필살기 → `super` 2프레임 반복 + 초상화 컷인(시그니처 표정) + 큰 자막 + 블립. 제나 까엉턴은 스프라이트 좌우 반전 토글로 회전 느낌.
- 대기 6초 → `flourish` 1회 후 idle 복귀(이동·공격 입력이 오면 즉시 취소).
- 결과 화면 → `win` 프레임 스프라이트 3배 + 시그니처 초상화 + 승리 대사(§4).

## 4. 음성·말투

- **음색 v2**(`VoiceProfile`): `baseHz`·`syllableMs`·`wave` + `accent: 'fall' | 'rise' | 'flat' | 'bounce'`(문장 끝 억양: fall = 마지막 노트 −3반음, rise = +3, bounce = 노트마다 ±1 교대, flat = 없음) + `spread`(반음 폭 배율 0.6~1.4) + `vibrato`.

| 멤버 | baseHz | syllableMs | wave | accent | spread | 인상 |
|---|---|---|---|---|---|---|
| 원이 | 210 | 90 | square | fall | 1.0 | 낮고 단단, 사투리 끝 내림 |
| 리브 | 330 | 85 | triangle | flat | 0.8 | 맑고 차분 |
| 미나미 | 400 | 60 | pulse | rise | 1.3 | 높고 빠름, 끝 올림 |
| 메이 | 350 | 55 | pulse | bounce | 1.2 | 조잘조잘 |
| 제나 | 250 | 70 | square | fall | 0.7 | 짧고 낮음 |

- **말버릇 대사**(`MemberDef.lines`, 각 4종 × 3문장 이상): `cheer`(응원 NPC로 등장할 때) · `win`(결과 화면) · `hurt`(피격 말풍선, 20% 확률) · `card`(카드 획득 시 한 마디). 문체: 원이 경상도 말투("마!", "~했나", "우이!") · 리브 차분한 존댓말 + "너도? 나도!" · 미나미 한국어에 일본어 감탄 섞기("에~", "스고이", "야호~!") + 가끔 "죄송합니다" · 메이 길고 빠른 조잘 + "기회는 그립감이 좋다" · 제나 짧은 말 + "그게 뭔데요?", "아뉘". 실제 발언 인용이 아니라 유행어 사전(v0.1 §5)의 표현으로 만든 창작 문장.
- 인트로 카드는 NPC 음색 유지. 응원 NPC 대사는 스테이지 데이터의 고정 문장 대신 그 멤버 `lines.cheer`에서 무작위.

## 5. 데이터·에셋

- `MemberDef`에 `lines`, `VoiceProfile`에 `accent`·`spread` 추가. `StageDef.outfit`(선택, 기본 `training`).
- 에셋: `public/assets/portraits/portrait_<m>.png` 5장, `public/assets/sprites/player_<m>[_<outfit>].png` 25장, NPC 9장·`life_<m>` 재생성. 도구: `npm run sprites`(스프라이트·NPC·life) · `npm run portraits`(초상화).
- 텍스처 키: `portraitTex(member) = 'portrait_<m>'`, `playerTex(member, outfit)`.

## 6. 테스트

- 순수: 초상화·스프라이트 시트 규격과 생성물 일치, 프레임 인덱스 무결성(0~14 빈틈 없음), 의상 5벌 × 5인 파일 존재, `voice` 억양 규칙(fall/rise/bounce/spread), 멤버 `lines` 각 3문장 이상·금칙어(실명) 없음.
- e2e: 기존 6개 유지 + 필살기 컷인에 초상화 텍스처 사용 확인(`textures.get('portrait_liv').frameTotal`), 결과 화면 win 포즈.

## 7. 결정

- 3등신(32×64)로 간다. 4등신은 프레임 제작량과 맵 통과성 부담이 커서 제외.
- 초상화는 "닮은꼴"이 아니라 시그니처 표정·머리 모양으로 식별한다.
- 말버릇 대사는 창작이며 유행어 사전 표현만 쓴다.
