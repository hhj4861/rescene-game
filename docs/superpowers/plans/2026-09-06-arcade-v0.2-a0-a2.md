> **orch-flow 실행 모드:** 이 플랜은 **트랙**(파일 소유권이 겹치지 않는 작업 묶음) 8개로 나뉘어 있고, 트랙은 3개 웨이브로 순서가 정해져 있다. 리드가 웨이브마다 `track-runner` 워커를 동시에 스폰한다. 워커는 자기 트랙의 태스크만 순서대로 수행하고, **소유권 glob 밖 파일은 절대 수정하지 않는다**(필요하면 보고에 적는다).

**Goal:** 현재 RPG 수직 슬라이스 위에서, 스테이지 1(연습생)을 아케이드 규칙(목숨·점수·게이지·유행어 필살기·음성 블립)으로 끝까지 플레이할 수 있게 만든다.

**Architecture:** 순수 TS 시스템(run/score/waves/cards/highscore/voice)을 먼저 TDD로 만들고, Phaser 씬은 그 위의 얇은 표현 계층으로 개편한다. 데이터(스테이지·웨이브·음색)는 zod로 검증한다. 구 RPG 시스템은 새 씬이 더 이상 참조하지 않게 된 뒤 마지막 트랙에서 삭제한다.

**Tech Stack:** Phaser 3.80 · TypeScript strict(noUncheckedIndexedAccess) · Vite 5 · Vitest 2 · zod 3 · tsx · Playwright · Web Audio API(직접 사용).

**Spec:** `docs/superpowers/specs/2026-09-06-rescene-arcade-v0.2-design.md` (이하 "스펙"). 연표·유행어 원문은 `docs/superpowers/specs/2026-09-04-rescene-story-design.md` §3·§5.

```ts
export type VoiceWave = 'square' | 'triangle' | 'sawtooth' | 'pulse';
export interface VoiceProfile { baseHz: number; syllableMs: number; wave: VoiceWave; vibrato?: number }
export interface VoiceNote { at: number; durationMs: number; freq: number; gain: number; wave: VoiceWave; slideTo?: number }
export const MAX_NOTES = 24;
export function decomposeHangul(ch: string): { cho: number; jung: number; jong: number } | null; // U+AC00~U+D7A3
export function speakNotes(text: string, profile: VoiceProfile): VoiceNote[];
```

- 규칙(스펙 §9.1): 한글 음절 → semitone = (jung % 7) − 3 + (cho % 3), 종성 있으면 −1, 길이 = syllableMs(+20 종성), gain 1. 영문·숫자 → semitone 0. 공백·`,`·`.` → 80ms 쉼(노트 없음). `!` → 직전 노트 gain ×1.3. `?` → 직전 노트 semitone +4. `~` → 직전 노트 길이 ×2 + `slideTo` = 직전 freq × 2^(2/12). 그 외 문자(`…`, 괄호 등)는 무시. `freq = baseHz * 2^(semitone/12)`(소수 2자리 반올림). 노트는 `at` 누적. 24개에서 끊는다.
