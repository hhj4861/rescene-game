# 리센느스토리 v0.2 아케이드 — 2차 플랜 (A4~A5: 스테이지 2~5·보스 기믹·신규 스프라이트·검증/밸런스)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **orch-flow 실행 모드:** 트랙 4개, 웨이브 2개. 웨이브 A(P1·P2·P3)는 동시에, 웨이브 B(P4)는 A가 전부 머지된 뒤. 워커는 자기 소유권 glob 밖 파일을 수정하지 않는다. 트랙끼리는 이 문서의 **공유 데이터 표**(적·보스 규격, 팔레트, 맵 오브젝트 이름)와 **Interfaces** 블록으로만 맞춘다.

**Goal:** 스테이지 2~5를 넣어 한 판(5스테이지 → 엔딩)이 완결되게 하고, 보스 기믹 4종·신규 잡몹 10종·보스 5종 스프라이트·스테이지별 타일 팔레트를 붙이고, 전 스테이지 e2e와 밸런스로 마무리한다.

**Architecture:** 1차 플랜의 데이터 주도 구조를 그대로 확장한다. 스테이지는 데이터 파일 + ASCII 맵 하나씩, 적·보스는 데이터 + 픽셀 템플릿, 보스 기믹만 `Boss` 서브클래스 4개와 CombatController의 알림 훅으로 붙인다. 맵 파서에 `jumppad` 오브젝트(밈의 파도 점프대)를 더한다.

**Tech Stack:** 1차 플랜과 동일 (Phaser 3.80 · TS strict · Vite · Vitest · zod · tsx · Playwright · Web Audio).

**Spec:** `docs/superpowers/specs/2026-09-06-rescene-arcade-v0.2-design.md` §3(스테이지 표·구간 규칙), §12(에셋), §13(테스트), §14(A4·A5). 연표 사실은 `docs/superpowers/specs/2026-09-04-rescene-story-design.md` §3.

## Global Constraints

- 1차 플랜의 Global Constraints 전부 유지(순수 시스템 no-phaser, 실명·사진·음원·닮은꼴 금지, 실존 타 그룹·개인·회사 금지, 음성 파일 미커밋, 커밋 트레일러, push·머지·PR 금지, 게이트).
- 스테이지 소개 문구는 아래 **인트로 표**의 문장을 그대로 쓴다(사실 확인된 연표). 워커가 새 사실을 지어내지 않는다.
- e2e는 리드의 5173 dev 서버를 쓰지 않는다: `E2E_PORT=<빈 포트> npm run e2e`.
- 자동 스크롤 구간은 이번 범위 밖이다(스펙 §3의 "타워 상승 구간"은 **세로로 긴 맵의 오르막 구간**으로 구현한다 — 결정 기록 §D).
