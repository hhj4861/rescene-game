# 플레이테스트 체크리스트 — 아케이드 v0.2

스펙 §13 "수동 체크리스트"를 따른다. 항목마다 ✅/❌와 메모. 스테이지 1~5(연습생·데뷔·신인의 길과
무명의 터널·역주행·첫 1위)가 모두 구현돼 있다 — 아래 "스테이지 클리어"는 공통 흐름, "스테이지별 기믹
확인"은 2~5 각각의 보스 기믹·점프대·중간보스를 사람이 직접 확인하는 절차다.

## 스테이지 클리어

- [ ] 스테이지 1(연습생)을 처음부터 보스 처치까지 2분 안에 클리어할 수 있는가
- [ ] 구간 4개(잠금선 → 웨이브 전멸 → "GO →") 흐름이 막힘 없이 이어지는가
- [ ] 보스 3페이즈 전환 연출·처치 → 결과 화면(처치 점수·콤보·노히트·목숨·시간 보너스 순서 합산) → 다음 스테이지 인트로(또는 엔딩)
- [ ] 스테이지 2~5 도 각각 2~3분 안에 클리어할 수 있는가(엔딩까지 한 판 10~15분)

## 스테이지별 기믹 확인 (2~5)

### 스테이지 2(데뷔) — 첫 카메라, 렌즈 기믹

- [ ] 평소엔 보스가 흰 틴트(닫힌 렌즈)로 무적 — 공격해도 피해 없이 튕겨 나가는가(회색 스파크·둔탁음)
- [ ] 3타 체인을 성공시키면 5초간 렌즈가 열려(이동 프레임으로 전환) 그동안만 피해가 들어가는가
- [ ] 2.5초마다(페이즈 2에서는 2발) 플래시 탄을 쏘는가

### 스테이지 3(신인의 길과 무명의 터널) — 구간 C 중간보스 + 침묵 기믹

- [ ] 구간 C(음원차트 타워, 세로 오르막)에서 발판·사다리를 타고 꼭대기까지 오르면 중간보스 TOP100
      문지기가 등장하는가 — 처치해도 스테이지 클리어가 아니라 구간이 이어지는가
- [ ] 스테이지 보스 침묵이 6초마다 무관심 안개를 2마리씩 소환하며 그동안 무적인가
- [ ] 소환된 안개를 3마리 처치하면 8초간 약점(정적, 붉은 틴트)이 열려 피해가 들어가는가
- [ ] 3초마다 양방향 충격파 탄을 쏘는가

### 스테이지 4(역주행) — 구간 D 점프대 + 카피캣 기믹

- [ ] 구간 D(밈의 파도)의 점프대를 밟으면 별도 키 없이 위로 튕겨 오르는가(0.3초 안에 다시 밟아도
      재발동하지 않는가)
- [ ] 카피캣 대장이 근접 공격은 0.4초 뒤 대시로, 원거리 공격은 0.4초 뒤 탄으로 따라 하는가
- [ ] 필살기(S)를 맞히면 3초간 경직하고 그동안 받는 피해가 2배가 되는가

### 스테이지 5(첫 1위) — 트로피 수호자, 페이즈별 무대 연출

- [ ] 페이즈가 바뀔 때마다(더쇼→음악중심→인기가요) 무대 배경색이 카메라 배경으로 바뀌는가(타일 교체 아님)
- [ ] 페이즈가 진행될수록 스포트라이트 드론 소환·대시·양방향 탄막이 늘어나는가
- [ ] 구간 A·C의 고속 추격형 잡몹(스포트라이트 드론·강화된 인이어 노이즈)이 회피 가능한 속도인가
      (밸런스 실측 기록 참고 — 무회피 봇 기준으로 가장 빨리 죽는 구간이라 사람이 직접 확인 필요)

## 컨티뉴 흐름

- [ ] 목숨 3개를 모두 잃으면 컨티뉴 화면이 뜨는가(제한 시간 안에 선택)
- [ ] 컨티뉴하면 점수가 0이 되고 현재 스테이지 첫 구간부터 다시 시작하는가
- [ ] 컨티뉴를 쓰지 않거나 이미 썼으면 게임 오버 → 이니셜 입력으로 가는가
- [ ] 스테이지 셀렉트로 시작한 판도 정상적으로 컨티뉴·게임 오버가 동작하는가

## 이니셜 입력(하이스코어)

- [ ] 게임 오버·엔딩 뒤 점수가 상위 10위 안이면 이니셜 입력 화면이 뜨는가
- [ ] ← → 로 글자를 고르고(영문 대문자·숫자·`.`) Enter로 확정하는가
- [ ] 타이틀 하이스코어 목록에 방금 등록한 기록이 순위대로 보이는가(`{ initials, score, member, stageReached, date }`)
- [ ] 10위 밖이면 입력 화면 없이 바로 타이틀로 가는가

## 음소거

- [ ] 스테이지 중 M을 누르면 배경음·효과음·음성 블립이 모두 즉시 꺼지는가
- [ ] 다시 M을 누르면 정상적으로 돌아오는가
- [ ] 음소거 상태가 새로고침 후에도 유지되는가(`localStorage`의 `settings.muted`)

## 음성 파일 교체 재생

- [ ] `public/assets/voice/`에 유행어 id로 이름 붙인 임시 `.ogg`(또는 `.mp3`)를 넣고 `npm run voice`를 돌린 뒤,
      그 유행어(필살기 발동·카드 획득·도감)를 트리거하면 합성 블립 대신 파일이 재생되는가
- [ ] 파일이 없는 다른 유행어는 여전히 합성 블립으로 대체되는가(콘솔에 404가 없는가)
- [ ] 파일을 지우고 `npm run voice`를 다시 돌리면 manifest에서 빠지고 블립으로 돌아가는가

## 밸런스 측정 — 스테이지 2~5 (2차 플랜 P4 Task 13)

**방법:** `npx vite --port 5185`로 별도 dev 서버를 띄우고, 개발 훅(`window.__rescene`) 없이 Playwright로
실제 키만 보냈다 — ArrowRight 유지(사다리 구간은 ArrowUp도 같이 눌러 자동 등반), 0.18초마다 A(공격),
0.7초마다 Space(점프), 하트가 줄면 0.5초 반대 방향으로 물러났다가 복귀, 4초 이상 카메라 스크롤이 멈추면
방향을 뒤집는 최소한의 반응만 준 "무회피 봇"이다. 진행 상황은 `window.__game.registry.get('run').state`
(하트·목숨·점수)로만 읽었다 — 이것도 순수 상태 읽기고 게임 로직을 조작하지 않는다.

**한계:** 이 봇은 실제 회피(피격 회피 타이밍·거리 유지)를 하지 못하고 늘 정면으로 들이받기만 하므로,
"사망 0~2회로 2~3분 클리어"라는 목표치(숙련된 플레이 기준)를 직접 재현하지 못한다 — 무회피 전략으로는
피격 쿨다운(1초 무적) 한계까지 계속 맞아 3목숨을 거의 항상 소진한다. 그래서 이 표의 "목숨 3개 소진까지
걸린 시간"은 절대적인 클리어 시간이 아니라, **스테이지 1(이미 받아들여진 기준선)과 같은 조건으로 상대
비교**하기 위한 지표로만 썼다.

| 스테이지 | 소요(3목숨 소진까지) | 사망 | 콘솔 오류 | 비고 |
|---|---|---|---|---|
| 1(연습생, 대조군) | 58.8s | 3 | 0 | 이미 받아들여진 기준선 |
| 2(데뷔) | 63.2s | 3 | 0 | 기준선과 동급(오히려 살짝 김) |
| 3(신인의 길) | 46.5s | 3 | 0 | 기준선보다 빠름(≈-21%) |
| 4(역주행) | 46.1s | 3 | 0 | 기준선보다 빠름(≈-22%) |
| 5(첫 1위) | 35.1s | 3 | 0 | 기준선보다 빠름(≈-40%) — 구간 A 부터 spd110~130 추격형 잡몹이 몰려 초반 피격이 잦다 |

**분석(수치 기반, `src/data/stages/*.ts`·`src/data/enemies.ts` 정적 계산):** 구간별 "웨이브 최소 스폰
소요시간"과 "총 hp"를 스테이지 1과 비교하면(엘리트 배율은 근사치),

| 스테이지 | timerSec | 잡몹 총 hp(대략) | 보스 hp | 초당 hp(잡몹+보스 / timerSec) |
|---|---|---|---|---|
| 1(대조군) | 180 | 1232 | 600 | 10.2 |
| 2 | 200 | 755 | 500 | 6.3 |
| 3 | 240 | 838(중간보스 450 제외 시) + 중간보스 450 | 700 | 8.3 |
| 4 | 200 | 1576 | 650 | 11.1 |
| 5 | 200 | 884 | 900 | 8.9 |

스테이지 4가 기준선보다 초당 hp 밀도가 약 9% 높지만(algorithm_golem hp120 이 5마리 등장), "크게 벗어난"
수준은 아니라고 판단했다. 스테이지 5가 무회피 봇 기준으로 가장 빨리 죽은 것은 hp 밀도가 아니라
enemy_spotlight_drone(spd130)·enemy_inear_noise(spd110, elite 웨이브) 같은 고속 추격형 잡몹이 구간
A·C에 몰려 있어 무회피 전략에서 피격 간격(1초 무적)이 거의 이론적 최솟값까지 줄기 때문이다 — 이건
"회피를 요구하는" 의도된 후반 난이도 상승으로 보이고, 총 hp/시간 예산 자체는 과도하지 않다.

**결론: 이번 라운드에서는 `count`·`intervalMs`·`timerSec`·`hp` 수치를 조정하지 않았다.** 근거: (1) 무회피
봇 기준 스테이지 1(기준선)과 같은 자릿수의 생존 시간을 보였고 극단적 이상치(수 초 만에 즉사·영구 정체)가
없었다, (2) 정적 hp/시간 예산도 기준선 대비 큰 이탈이 없었다(스테이지 4가 가장 높지만 +9%대). 다만
스테이지 5 구간 A·C의 고속 추격형 잡몹 밀도는 사람이 직접 플레이해 "회피 가능한 난이도인지"를
확인하는 후속 수동 플레이테스트를 권장한다(아래 체크리스트의 스테이지 5 항목 참고).
