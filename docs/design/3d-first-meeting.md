# 첫 만남 3D 프로토타입

2026-09-29. 기존 정적 일러스트 장면에서 실제 카메라 이동과 캐릭터 동작을 검증하기 위한 **첫 장면 프로토타입**이다. 다섯 멤버의 고유 얼굴·의상·헤어를 완성한 최종 디자인이나 전체 게임의 3D 전환으로 간주하지 않는다.

## 실행과 범위

```sh
npm ci
SURVIVAL_PORT=4321 SURVIVAL_DATA_DIR=/tmp/rescene-3d-preview node server/survival/server.mjs
```

접속: `http://127.0.0.1:4321/survival-3d.html`. `/survival.html`과 기존 AI·시즌 흐름은 그대로 유지한다. 이 프로토타입은 서버에서 정적 파일만 읽고 API 명령, 모델 호출, 저장 변경을 하지 않는다. 인사 문구는 이 장면을 검증하기 위해 작성한 고정 예시이며 실제 인물의 발언이 아니다. 인사 진행 상태는 해당 페이지에만 존재하고 새로고침하면 초기화된다.

- 회의실, 목재 테이블과 여섯 의자, 식물, 책장, 바다·마을·등대, 다섯 캐릭터 모두 실제 메시다. PNG 배경에 입체 효과만 더한 구성이 아니다.
- 카메라: 함께 앉기 / 공간 둘러보기 / 멤버 근접 / 시점 초기화. 마우스·터치 드래그로 회전, 휠·두 손가락으로 확대. 캔버스에 초점을 맞춘 뒤 방향키로 이동, Home으로 초기화, 1–5로 멤버 선택.
- 멤버를 직접 누르거나 하단 버튼으로 선택한다. 시선·호흡·눈 깜빡임과 인사 손짓이 있으며 다섯 인사 완료를 표시한다.
- 동작 정지, `prefers-reduced-motion`, 백그라운드 렌더 중단, WebGL 실패·컨텍스트 손실 안내를 지원한다.
- Three.js 0.180.0을 lockfile에 고정했다. 라이브러리는 로컬 서버의 두 파일만 허용하여 제공한다. CDN 요청, 인라인 스크립트, CSP 완화가 없다.
- 재질이 같은 정적 메시를 결합해 렌더 호출을 줄이되 머리·눈·팔·배의 움직임과 멤버 선택 경계는 유지한다. GPU 자원은 페이지 종료 시 해제한다.

## 시안과의 대응

색상 기준은 종이 `#f6f1e5`, 잉크 `#343b3b`, 바다 UI `#315d68`, 목재 `#b99262`, 세이지 `#84957b`다. 제목·대화에는 명조/Georgia 계열, 조작 UI에는 시스템 고딕을 사용한다. 상단 브랜드 → 왼쪽 장소 → 큰 공간 → 하단 대화 흐름을 유지한다. 모바일은 3D 장면·멤버 선택·대화·행동 순서로 배치한다.

승인한 시안의 바다 조망, 원형 테이블, 빈 여섯 번째 의자, 멤버별 의상 색, 크림·청록 UI와 대화 흐름을 옮겼다. 시안은 고품질 렌더 스타일의 이미지였고, 현재 캐릭터는 코드로 제작한 단순화된 관절 모델이다. 따라서 시안과 동일한 인물 묘사·재질 완성도는 **미달성**이다. 실시간 모바일 장치의 프레임 성능도 브라우저 에뮬레이션만으로 보장하지 않는다.

다음 디자인 단계는 전용 캐릭터 GLB(고유 얼굴·헤어·의상, 스키닝·표정)와 정교한 회의실 재질을 제작해 이 카메라·UI·상호작용에 연결하는 것이다. 이번 단계는 모델의 관절 그룹을 움직이는 방식이며, 스킨 메시 리깅·립싱크·공연 안무는 포함하지 않는다. 다른 네 스토리라인이나 Gemini 대화를 이 장면에 연결한 상태도 아니다.

## 검증

`node tools/survival/verify-3d.mjs`는 독립 포트·저장 폴더에서 Chromium 및 WebKit의 실제 WebGL 렌더링, 메시 선택, 다섯 인사, 카메라·드래그·키보드, 일시정지, 모바일 배치, 감소된 동작, WebGL 사용 불가 안내를 검증한다. 외부 요청·AI 호출이 없고 사전 생성한 시즌 파일이 바이트 단위로 보존되는지 확인한다. 결과 JSON과 스크린샷은 출력한 임시 증적 폴더에 저장한다.

기존 게임 회귀: `node --test tests/survival/*.test.mjs` — 41개 통과.

Three.js API 참고: [WebGLRenderer 공식 문서](https://threejs.org/docs/#api/en/renderers/WebGLRenderer). 의존 라이선스는 `node_modules/three/LICENSE`의 MIT 조건을 따른다. 캐릭터와 공간은 이 저장소에서 코드로 제작했으며 외부 모델을 가져오지 않았다.
