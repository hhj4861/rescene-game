# 결과 화면의 멤버별 노래 선물

2026-10-05 사용자 승인: 갑작스러운 자동 가창을 없애고 다섯 멤버 모두 결과 화면의 ‘노래 선물’ 버튼으로 듣는다. 5,000점 자동 재생과 플레이 중 다시 듣기 버튼은 제거했다. 이전 누적 저장값은 호환성을 위해 보존하며 새 점수로 갱신하지 않는다. 점수·목숨·진행에는 영향을 주지 않는다.

원이는 피버 시작/10콤보 단위의 큰 성과에만 짧은 리액션을 재생한다. 제나의 매치/연쇄/아이템 리액션은 4초 간격의 기존 순환을 유지한다. 클리어 유행어가 먼저 나오고, 가창은 버튼을 눌렀을 때만 시작한다. 소리 또는 멤버 음성이 꺼져 있으면 가창을 재생하지 않으며 중단·배경 전환·화면 이탈을 지원한다. 리브 곡 아이템은 별도 기능이다.

원이는 공식 원본 전체, 메이·제나·리브는 기존 짧은 가창 파일을 사용하며, 미나미는 공식 원본 영상 링크로 제공한다. 공식 Shorts와 전체 커버 모두 실제 임베드 확인에서 오류 150이 발생했으므로 재생이 안 되는 플레이어 대신 YouTube에서 열도록 했다. 개인 커버를 그룹곡이나 합성 음성으로 대체하지 않는다. 미나미 제목/채널/길이는 공개 메타데이터로 확인했다. YouTube 새 탭의 재생·음량은 해당 플레이어에서 조작한다. 출처 표시는 이용 허락 취득을 뜻하지 않는다.

검증: 기존 네 파일의 디코딩·비무음 신호, 다섯 멤버별 수동 연결, 점수 경계에서 자동 재생 없음, 클리어 음성·음소거·실패 후 재시도·이탈 중단을 Chromium/모바일 Chromium/WebKit에서 확인한다. 실제 YouTube 네트워크 재생 확인은 모의 IFrame API 회귀 테스트와 구분한다.

## 2026-10-07 아이템 노래 업데이트

원이·메이·제나는 노래 아이템을 먹을 때도 재생한다. 원이는 41초 원본을 한 번, 메이·제나는 기존 짧은 클립을 최대 60초 반복한다. 원이의 2.8초 반복 문제를 없애기 위해 자산과 캐시 URL을 갱신했다. 일시정지 시간은 제외하며 다음 스테이지에서도 이어 듣고, 재생 중 추가 아이템은 곡을 처음으로 돌리지 않는다. 새로고침은 소모된 노래를 재생하지 않는다.
