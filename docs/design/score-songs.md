# 누적 점수 노래 보상

원이·메이·리브의 일반 적 처리, 연쇄, 아이템 획득 때 자동으로 나오던 짧은 멤버 말소리를 제거했다. 타격 효과음과 캐릭터 반응은 유지한다. 미나미 펌프는 이 기능에서 제외한다. 2026-10-05 사용자 요청으로 제나도 노래 보상에서 제외하고, 매치·연쇄·아이템 획득 시 기존 세 가지 리액션 음성을 4초 간격으로 번갈아 재생하도록 복구했다. 제나의 클리어 유행어는 유지하며, 이전 노래 보상 저장값은 보존하되 누적·자동 재생·다시 듣기에는 사용하지 않는다. 기존 스테이지 클리어 유행어와 리브 곡 아이템 특수공격은 유지한다.

## 점수와 저장

- 멤버별 누적 획득 점수 5,000 / 10,000 / 15,000점마다 해당 멤버 노래를 한 번 재생한다. 스테이지·새 도전을 넘어 유지하며, 브라우저 저장 데이터를 지우면 초기화된다.
- 한 판의 이전 최고 점수보다 증가한 점수만 더한다. 가짜 파이리 감점 후 복구한 점수로 보상을 반복 획득할 수 없다.
- 한 번에 여러 기준을 넘으면 가장 높은 기준의 보상 한 번으로 합친다. 재생 중 추가 보상은 최대 한 번만 대기한다.
- 보상 기록은 재생 전에 저장한다. 일시정지·화면 이탈·새 도전 시 대기 재생은 취소하고 재개/새로고침으로 재생하지 않는다. 소리/멤버 음성이 꺼져 있을 때도 획득 기록은 저장한다.
- 기존 저장 데이터는 진행 중 점수를 기준값으로만 읽고 소급 보상을 만들지 않는다. 새 점수부터 누적한다.
- 이미 받은 노래는 다시 듣기로 재생할 수 있다. 미디어 오류는 진행/목숨/보상을 되돌리지 않고 재시도 안내를 보여준다.

그룹 곡을 개인 커버 대신 연결하지 않는다. 실제 원본의 짧은 구간이며 합성/복제 음성이 아니다. 원이는 사용자가 해당 챌린지 선택을 확인했다. 원본 메타데이터·공식 영상 화면과 짧은 구간을 확인했고, 원이 시점은 로컬 전사로 보조 확인했다. 자동 전사는 음질/가창 평가의 근거가 아니며 직접 청취 검수를 대신했다고 주장하지 않는다. 원본 및 전체 전사·다운로드 작업본은 Git에 포함하지 않는다. 출처 표시는 별도의 이용 허락 취득을 의미하지 않는다.

노래 보상 재생 중 합성 BGM과 리브 아이템 영상 볼륨을 0으로 낮춘다. 완료·실패·취소 시 이전 배경음 설정을 유지하며 복원한다. 동시에 클리어하면 노래 보상이 자동 유행어보다 우선한다.

검증: 누적/감점/저장 마이그레이션 단위 테스트, 세 멤버 보상 연결 및 기존 네 멤버 파일 디코딩·비무음 신호 확인, 5,000·10,000 보상/새로고침/음소거/오류 후 재시도/동시 클리어/리브 영상 볼륨 복원을 데스크톱 Chromium·모바일 Chromium·모바일 WebKit에서 확인한다.
