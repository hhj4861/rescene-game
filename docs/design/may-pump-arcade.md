# 메이 공방·미나미 곡 선택 — 2026-10-03

사용자 요청: 메이는 보글보글처럼 방울 전투를 강화하고 너무 쉬운 난이도를 높인다. 미나미는 음악이 안 들리는 문제를 보완하고 곡·스테이지를 고르게 한다. 기존 승인된 캐릭터를 유지한다. 리브 난이도 PR #20의 운영 배포와는 별도 변경이다.

## 메이

- 1단계 목표 3 → 6마리. 이후 8/10/12/14, 장기적으로 최대 24마리까지 증가한다. 기본 적은 4마리이며 단계에 따라 동시 최대 7마리다.
- 적은 같은 층에서 메이를 추격하고 위층으로 뛰거나 아래층으로 떨어져 따라온다. 단계별 이동 속도 72~120px/초, 등장 간격 1.6~0.9초다. 35초부터 25% 더 빨라진다.
- 방울에 가둔 적에게 접근해 F/방울 버튼 또는 접촉으로 터뜨린다. 원거리 130px 일괄 팡을 64px 근접 팡으로 바꿨다. 85px 이내로 이어진 방울들은 연쇄로 터지고 점수 배율을 받는다.
- 3~4.5초 동안 못 터뜨리면 탈출해 붉은색으로 변하고 35% 더 빨라진다. 남은 포획 시간을 방울 위에 표시한다. 발사된 빈 방울은 처음에는 전진하고 이후 느리게 떠오른다.
- 짝수 단계는 발판 좌우 배치를 반전한다. 기존 이동·점프·뒤돌기·방울 키와 속도/큰 방울 아이템, 멤버 음성을 유지한다.
- `mayVersion:2` 저장. 이전 1 버전과 버전 없는 저장은 점수·단계·목숨을 유지하며 새 적 물리 상태를 보충한다. 이전 라운드의 발판 배치는 그대로 유지한다. 연쇄 팡도 짧은 메이 반응 음성을 사용한다.

## 미나미

기존 펌프 BGM은 작은 볼륨의 실시간 합성음이었다. 사용자 기기에서 무음이 된 정확한 환경은 재현하지 못했으며, 이번에는 실제 연속 음원 재생·가청 신호 검사·복구 UI로 보완한다.

| 곡 | 속도 | 길이 |
| --- | ---: | ---: |
| Five Steps, One Stage | 120 BPM | 60초 |
| 바닷바람 스텝 | 108 BPM | 60초 |
| 네온 러시 | 144 BPM | 60초 |

- 세 곡 모두 프로젝트 자체 제작 **보컬 없는 연주곡**이다. 제3자 곡이나 멤버의 노래를 이 펌프 음악에 사용하지 않는다. `music.js` 악보를 `scripts/render-pump-music.mjs`로 MP3 렌더링한다. 재생 길이/박자와 채보가 같은 악보 정보를 사용한다.
- 주크박스에서 곡·난이도를 선택하고 8초 미리 듣기 후 시작한다. 가볍게(1단계), 신나게(3단계·동시 발판), 뜨겁게(6단계·반 박자) 중 선택한다. 새 도전은 선택한 단계/목숨 3개이며, 별도 ‘저장된 무대 이어하기’로 기존 플레이를 재개한다.
- 곡별 BPM과 방향 패턴에 맞춘 채보를 사용한다. 목표 횟수를 먼저 채워도 곡이 끝나기 전 클리어되지 않으며 60초까지 살아남아야 한다. 다음 단계는 선택했던 곡을 유지하며 클리어 후 새로고침해도 저장된 다음 단계와 곡으로 이어갈 수 있다.
- 음악은 클릭에서 재생을 시작하고 준비 중에는 게임 시간을 멈춘다. 재생 실패는 안내와 일시정지로 처리해 음악 없이 목숨이 줄지 않게 한다. ‘음악 다시 켜기’로 음소거 또는 실패를 복구한다.
- 음악은 Web Audio 출력 버스를 통과해 멤버 음성 중 볼륨 감소를 유지한다. 곡 변경·미리 듣기 전환·일시정지·홈·탭 숨김은 이전 음악을 정지하고, 재개는 저장한 시간부터 재생한다. 명시적으로 끈 소리/BGM 설정은 새 게임 이동에도 유지한다.
- `songId`를 스냅샷에 저장한다. 이전 저장에 songId가 없으면 기존 Five Steps 곡으로 이어받는다. 기록은 기존 미나미 공용 단계/최고 점수 구조이며 곡별 리더보드는 추가하지 않는다.

## UI와 검증

`frontend-design` 지침에 따라 기존 오락실의 잉크 #234454, 종이 #fff9e9, 라일락 #ccb9dc, 민트 #92bfb3, 노랑 #f5d77e를 유지한다. Jua 제목/Noto Sans 본문, 미나미 캐릭터와 음반 모양의 선택 패널을 사용한다. 곡과 난이도는 키보드로도 선택 가능하고 선택 상태를 표시한다.

- 단위: 메이 근접/연쇄·발판 추격·탈출 강화·반전 발판 도달·이전 저장 복원. 펌프 3곡 × 3난이도 전체 채보를 박자에 맞춰 입력해 60초 완주, 조기 클리어 방지, 이전 곡 저장 호환을 검증한다.
- 브라우저: 실제 MP3의 재생과 Web Audio RMS 출력, 3곡 미리 듣기/선택, 난이도/곡 저장·새로고침, 정지/복구, 음악 요청 실패 시 목숨 유지, 메이 연쇄 입력과 강화 적 저장을 검증한다. 모바일 Chromium/WebKit은 에뮬레이션으로 실기기 청음 확인은 별도다.
- 로그·렌더 중간물·캡처는 사용자 지정 iCloud `rescene-game/may-pump-20261003/`에 보관한다. 운영 적용은 이 변경 PR의 승인 후 진행한다.
