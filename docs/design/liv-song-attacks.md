# 리브 곡 아이템과 난이도 — 2026-10-04

곡 아이템을 획득하면 10초 동안 해당 곡의 공식 YouTube 영상과 특수공격을 실행한다. 기존 펌프의 검증된 공식 5곡을 공유하며 음원을 추출하지 않는다. 플레이어와 기본 컨트롤·원본 링크를 보여준다.

아이템은 쓰러뜨린 적의 이웃 길에 나타나므로 길을 바꿔 획득한다. 새 아이템은 이전 효과와 곡을 교체한다. 소리·BGM 설정을 따르고 멤버 음성 설정과 구분한다. 실제 영상이 재생되는 동안 자체 BGM을 멈추고, 효과 종료·영상 실패·자동 재생 차단에는 기본 BGM을 유지한다. 영상 실패가 전투를 중단하거나 아이템을 취소하지 않는다. 일시정지·다른 화면 이동 시 음악을 멈추며 저장 복원은 남은 효과 시간과 영상 구간을 이어간다.

기본 적 체력은 8→12, 기본 등장 간격은 1.65→1.35초, 기본 보스 체력은 180→240이다. 네 번째 생성마다 다른 길에 적을 추가하며 일반 구간의 생성 상한은 12명이고, 보스 등장 후에는 호위를 포함해 6명 미만일 때 추가 생성한다. 이미 등장한 적은 유지한다. 양수 게이트는 +2~3과 ×1.5, 대원 상한은 48이다. × 게이트의 소수 병력은 내림한다. 새 판의 초기 네 게이트 동안 해당 단계의 압력을 점진적으로 적용해 고단계에서 시작하자마자 막히는 것을 방지한다.

이전 응원봉·음표 요정·별똥별·오로라 날개 저장은 LOVE ATTACK·Pinball·Heart Drop·New World로 옮기고 남은 시간·점수·목숨·획득 횟수는 유지한다. 버전이 있는 새 저장의 알 수 없는 아이템이나 손상된 효과/탄환은 거부한다.

단위 검사는 곡별 실제 피해·반사·관통/왕복·만료·저장 호환·게이트 약화·동시 등장·유한한 난이도 상한을 확인한다. 180ms마다 판단하는 동일 모의 플레이어의 20개 시드로 1·5·10·20·50단계가 계속 공략 가능함을 확인하며, 이 수치는 사람의 승률이 아니다. 브라우저 검사는 공식 플레이어 요청·BGM 전환·음소거·정지·저장 이어하기·실패 복구를 확인하고, 실제 YouTube 재생은 별도로 검사한다.
