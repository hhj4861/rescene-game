# 게임 선택 슬라이드와 신라빵 조작 개선

2026-10-02 · PR #14 머지 및 운영 배포 완료 · 소스 `5d0b8f2`

## 화면과 조작

기존 심시티풍 멤버 캐릭터, Jua 제목, 민트·피치·로즈·라일락·하늘색 오락기를 유지한다. 중앙 오락기의 양옆에 다음 게임이 보여 손가락으로 넘기는 방향을 알 수 있다.

- 모바일 스와이프와 트랙패드 가로 스크롤은 브라우저 기본 스크롤 스냅을 사용한다.
- 이전/다음, 멤버 이름, 좌우 방향키, Home/End로 같은 게임을 선택할 수 있다. 자동 넘김은 없다.
- 마지막에 플레이한 게임을 이번 탭의 홈 화면에서 다시 선택한다. 기존 스테이지·목숨·최고 기록 저장 형식은 유지한다.
- 키보드 이벤트는 선택 화면 안에서만 처리한다. 포커스가 잡힐 때 강제로 재중앙 정렬하지 않아 포인터 클릭 좌표가 바뀌지 않는다.

## 제나 신라빵

[애니팡3 공식 소개](https://play.google.com/store/apps/details?hl=ko&id=com.sundaytoz.kakao.anipang3.service)의 매치3·연쇄 플레이를 참고하며, 기존 빵 그래픽과 멤버 디자인을 사용한다.

- 마우스/손가락으로 상하좌우 이웃한 빵에 드래그하면 한 칸 교환한다. 기존 두 번 터치와 키보드 선택도 지원한다.
- 일정 거리 이상 이동해야 드래그로 인식한다. 대각선, 바깥 칸, 취소된 포인터는 교환하지 않는다.
- 맞는 교환은 0.16초 이동 → 0.24초 터짐 → 0.42초 낙하로 보인다. 연쇄가 생기면 터짐/낙하를 반복한다.
- 살아남은 빵은 원래 행에서 아래로 떨어지고 새 빵은 판 위쪽에서 내려온다. 연출 중 입력은 잠근다.
- 맞지 않는 교환은 왕복 연출 후 돌아오며 교환 횟수를 차감하지 않는다.
- 판·점수·난수 결과를 먼저 확정하고 각 단계의 화면을 재생한다. 저장 시 확정된 판을 보존하므로 재개할 때 연출과 보상을 중복하지 않는다.
- 클리어 화면은 낙하가 끝난 뒤 표시한다. 목표를 이미 채운 경우 연출 때문에 제한시간 패배가 발생하지 않는다.

## 모든 게임 BGM

기존 다섯 오리지널 연주곡은 그대로 사용한다. 새 게임 시작 버튼의 사용자 입력으로 오디오를 활성화하고 게임별 곡이 기본 재생되는지 실제 Web Audio 출력 신호로 검증한다. 소리/BGM을 직접 끈 설정은 이번 탭에서 유지한다. 일시정지와 홈 이동에서는 이전 곡을 정지한다. 브라우저 자동재생 정책 때문에 홈 진입만으로 소리를 시작하지 않는다.

## 검증

Node: 낙하 전후의 열 순서, 화면 위 새 빵 생성, 다중 연쇄, 입력 잠금, 잘못된 교환, 중간 저장/재개, 제한시간 직전 클리어를 확인한다.

Playwright: 데스크톱 Chromium, 모바일 Chromium, iPhone 크기의 WebKit에서 선택/시작/재개/기록/음성과 다섯 BGM 실제 출력을 확인한다. 모바일 Chromium에서는 CDP 터치 입력으로 홈 스와이프와 빵 교환을 실행한다. WebKit의 마우스 드래그 및 터치 탭 검증은 실제 iPhone 손가락 검증을 의미하지 않는다.

로컬 검증 결과: Node 33개 통과, lint/build 통과. 전체 브라우저 회귀 112개 통과·환경별 5개 제외 후, 시간 경계 보완 관련 신라빵/BGM 19개 추가 통과·2개 제외. 제외 항목은 CDP 터치 주입을 지원하지 않는 환경과 데스크톱 멀티터치 테스트다. 마지막으로 저장된 클리어 판의 제한시간 경계는 Node 회귀 검증에 포함했다.

데스크톱과 320px 모바일 화면을 직접 검토해 캐릭터·오락기 외형 유지, 인접 카드 노출, 가로 넘침 없음과 낙하 중 빈칸/위쪽 빵 이동을 확인했다. 실제 기기 검증은 이번 결과에 포함하지 않는다.

테스트 산출물은 사용자 지정 iCloud 작업 루트의 `rescene-game/game-carousel-20261002/`에 저장한다. 최종 로컬 미리보기 빌드는 `build-reviewed/`이다. 사용자 승인 후 PR #14를 머지하고 CI 산출물로 운영 배포했다. [배포 기록과 공개 주소](../deployment/arcade-pages.md)를 참고한다.

운영 배포 후 공개 주소에서도 브라우저 115개가 통과했고 환경별 5개는 제외됐다. CI 빌드와 운영 파일 12개의 SHA-256이 모두 일치했다. PR/main CI도 성공했다.
