## 저장 호환

기존 게임 ID와 최고 기록 키는 유지한다. 새 진행 중 화면에는 schema 3을 사용한다. 예전 주행·블록·촬영·2방향 리듬·수집 화면은 새 규칙에 복원하지 않고, 도달 단계·최고 단계·남은 목숨을 보존한 채 해당 단계부터 새 게임으로 시작한다. 새 게임은 보드·적·무작위 상태·남은 시간을 저장하고, 재접속 후 명시적으로 계속하기를 눌러야 시간이 흐른다. 저장은 이 브라우저에 한정한다.

## 소리와 음성

효과음과 멤버 음성은 기본 켜짐이다. 게임 시작/계속하기의 사용자 입력에서 오디오를 활성화하고 클리어 때 기존 실제 멤버 MP3를 재생한다. 사용자가 끈 설정은 해당 탭의 게임 전환에서도 유지한다. 멤버 음성 재생 실패는 다시 듣기로 복구하며 저장과 다음 단계 진행을 막지 않는다. 새 음성 합성이나 API 사용은 없다.

## 시각 자산

기존 승인된 멤버 캐릭터를 그대로 사용한다. 방울 적·빵·타워·발판·정원은 게임의 Canvas 도형으로 그렸다. 파이리 PNG는 기존 공개 스프라이트를 사용한다(생성 이미지가 아님).

새 게임별 입력·득점·실패, 난이도 상승, 저장 이전 및 복원, 5→6단계, 실제 MP3 신호와 자동 재생, 작은 화면과 키보드/터치 조작을 검증한다. 검증 결과:

- `npm test`: 22개 통과. 모든 발판 도달, 타워 자원/발사, 특수 빵, 5방향 동시 판정, 활성 상태 저장 복원 포함.

- 운영 배포 후 같은 브라우저 검증을 실제 공개 주소에서도 실행해 86개 통과, 데스크톱 터치 전용 1개 제외를 확인했다. 공개 파일 12개가 CI 산출물과 SHA-256 기준으로 모두 일치했다. 배포 산출물·공개 검증 기록은 `rescene-game/arcade-deploy-20261002/`에 보관한다.

## 승인된 편집 훅 복구

실패한 Delete+Add 패치가 미종료로 남아 핵심 파일 편집을 차단했다. 사용자 승인 후 `tools/repair-task-finish-duplicate-patch.py`로 정확한 호스트 거절·경로·세션·턴·호출 시간·단일 귀속을 대조하는 복구 분기를 추가했다. 과거 로그 17MB 한 건을 읽도록 레코드 상한을 16→32MB로 조정했다. 실행 증거가 있거나 중복·누락·동적 호출·다른 경로/턴이면 복구하지 않는다. 실패 종료 코드 `null`을 유지하고 소유권·커밋·푸시 검사는 유지한다.

회귀 테스트 9개와 실제 실패 기록 대조를 통과했다. 설치 전 SHA-256을 확인하고 전역 훅의 `backups/` 아래 원본을 보존했다. 설치된 훅에서 실패 종료 증거가 기록됐고, 실제 후속 model.js 편집이 허용됨을 확인했다. 과거 다른 호출의 기록·원본 세션 로그·DB를 수동 삭제하거나 완료로 바꾸지 않았다. 복구 도구는 게임 실행·CI에서 자동 실행하지 않는다.
