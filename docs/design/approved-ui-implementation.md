## 유지한 게임 계약

- 20팀·10라운드·제안→토론→투표→공연→심사→회고→경험 저장의 엔진/API/저장 스키마를 유지한다.
- UI의 연습은 `practice - recovery`, 휴식은 `recovery`다. 서버의 `practice`는 휴식을 포함하는 총 PP이며 합계 12다. 화면에서 연습과 휴식을 분리해 배분해도 저장 계약은 같다.
- 화면 표시 순서(원이·리브·미나미·메이·제나)와 서버 멤버 인덱스를 분리해 잘못된 멤버에게 PP가 저장되지 않도록 한다.
- 대결 패배 후 생존, 탈락, 결승 준우승, 우승을 구분한다. 시안에 적힌 순위나 예시 대사를 실제 게임 데이터처럼 고정하지 않는다.
- 자료 검수·철회/재검수, 실패 단계 재시도·취소, 성장 기록, 읽기 전용 시즌 이력에 계속 접근할 수 있다.
- 공연의 오디오는 기존 합의안/수행 증거로 생성하는 60초 연주곡이다. 그림은 승인된 정적 일러스트이며 파트 표시·조명만 시간에 맞춰 변한다. 인물의 팔다리를 움직이는 리깅 애니메이션이나 실제 가창을 구현했다고 주장하지 않는다.
- 페이지 이동·탭 숨김·재렌더 시 재생 자원을 정리하고 reduced-motion 설정을 반영한다.
