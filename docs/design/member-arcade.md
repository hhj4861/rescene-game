# 리센느 작은 오락실 — 첫 두 게임

2026-09-29. 사용자 승인에 따라 생존 시즌 경영 흐름의 확장을 멈추고, 이전 심시티풍 캐릭터를 재사용한 멤버별 아케이드 체험판을 만들었다. 첫 범위는 원이의 바닷길 드라이브와 메이의 조각 공방이다. 제나·미나미·리브 게임은 이번에 구현하지 않았고 첫 화면에서 준비 중으로 표시한다.

## 타깃과 목적

- 타깃 가설: 멤버와 캐릭터에 가벼운 관심이 있고 휴대폰으로 잠깐 놀고 싶은 사람. 게임 숙련을 전제하지 않는다.
- 사용자 가치: 메뉴 학습 없이 즉시 시작하는 짧은 놀이와 개인 기록 도전.
- 목적: 게임 반복을 통해 멤버 이름과 외형에 친숙해지고 다른 멤버의 게임도 경험하게 한다.
- 기대효과는 아직 가설이다. 설명 없이 첫 행동을 하는지, 다시 플레이하는지, 멤버 이름을 기억하는지 실제 사용자 관찰로 확인해야 한다. 자동 테스트가 재미를 증명하지는 않는다.

## 캐릭터와 게임 배정

| 멤버 | 게임 | 연결 근거 | 이번 상태 |
|---|---|---|---|
| 원이 | 바닷길 드라이브 | 동료가 의지할 수 있는 리더 지향, 운전 배우기 | 플레이 가능 |
| 메이 | 조각 공방 | 바느질·인형 옷 만들기, 스티커·다이어리 취미 | 플레이 가능 |
| 제나 | 깜짝 포토부스 | 재미있는 표정·분위기 메이커 | 기획 후보 |
| 미나미 | 댄스 타임 | 안무·댄스 챌린지 | 기획 후보 |
| 리브 | 별빛 산책 | 사진·산책 취미 | 기획 후보 |

근거는 [Hellokpop 직접 인터뷰](https://www.hellokpop.com/interview/exclusive-interview-introducing-rescene/)와 [View of the Arts 직접 인터뷰](https://viewofthearts.com/2025/12/24/rescene-on-their-third-mini-album-lip-bomb-training-days-and-favourite-berries/)다. 게임 배정·대사·행동은 창작이며 실제 멤버의 게임 취향·실력을 주장하지 않는다.

## 디자인 결정

바닷가 오락실의 두 기계를 주인공으로 삼았다. 민트(#92bfb3)는 드라이브, 피치(#eab19b)는 공방을 구분한다. 짙은 청록(#234454)으로 기계 테두리와 조작 버튼을 표시하고 종이색(#fff9e9), 노랑(#f5d77e), 옅은 바다색(#8ccdd5)을 사용한다. Jua는 게임 제목과 큰 점수, Noto Sans KR은 조작 안내에 사용한다. Google Fonts가 불가능하면 시스템 글꼴로 표시한다.

첫 화면은 제목 → 두 오락기 → 준비 중 친구들 순서다. 오락기 안에 실제 게임의 작은 화면과 기존 캐릭터를 함께 표시한다. 실행 화면에서는 게임판을 중앙에 크게 두고 캐릭터의 한마디를 곁들인다. 모바일은 세로 한 열이며 조작 버튼을 게임판 바로 아래에 둔다. 복잡한 마을 이동·성장 배분·긴 대화·게임 시작 전 로그인은 없다.

## 원본 캐릭터

심시티의 `src/sim/DistrictScene.ts`가 사용하는 `public/assets/dolls/rescene-dolls-v1.webp`를 정확히 복사했다. 이번 파일은 `public/arcade-room/town-cast.webp`, SHA-256은 `ef088f158ecc228e3c72ee0207fc97c62503d9b95b6c3a2dec9e72b29baad888`이다. 원본과 복사본의 해시 일치를 확인했다. 기존 `src/ui/dolls.ts`의 녹색 배경 제거와 셀 분할 규칙을 브라우저 로딩 시 재사용한다. 새 얼굴 생성이나 모델 변형은 없다.

이 아틀라스의 열 순서는 **원이·리브·미나미·메이·제나**다. 반실사 시안 01~05의 순서를 이 아틀라스에 적용하지 않는다. 첫 화면의 준비 중 멤버는 제나·미나미·리브 순서다.

## 규칙과 조작

### 원이

최대 60초, 세 번 부딪히면 종료. 자동차는 자동 전진하고 좌우 버튼/방향키 또는 길 터치로 세 차선 중 하나를 고른다. 별 하나 100점, 주행 초당 10점. 한 줄에 장애물은 하나만 생성해 두 차선을 남긴다. 충돌 후 1.4초 보호 시간을 둔다.

### 메이

8×12 격자에서 조각을 맞춘다. 좌우 이동, 회전, 내려놓기 버튼을 제공하며 방향키와 Space도 지원한다. 점선은 착지 위치다. 한 줄 이상을 동시에 채우면 삭제·보너스 점수. 60초 또는 새 조각을 놓을 자리가 없으면 종료한다. 홀드·아이템·복잡한 특수 규칙은 없다.

### 공통

일시정지와 탭 전환/창 포커스 상실 시 시간을 멈춘다. 완료 결과에서 재도전하거나 게임 선택으로 돌아간다. 최고 기록만 별도 키 `rescene.small-arcade.v1`에 저장하고 기존 게임 저장에는 접근하지 않는다. 저장이 차단된 브라우저에서도 플레이하며 결과 화면에 저장 실패를 알린다. 효과음은 처음에는 꺼져 있고 사용자가 켜면 짧은 합성음을 사용한다. 실제 목소리·음원을 사용하지 않는다.

첫 두 게임은 브라우저에서 즉시 동작한다. 게임 중 AI 요청·대기·비용이 없다. 기존 LiteLLM 시즌 구현과 설정은 변경하지 않았다.

## 실행과 검증

```sh
npm run arcade:dev
# http://127.0.0.1:4325/arcade-room.html
npm run arcade:test
npm run arcade:build
```

빌드 결과는 `dist-arcade-room/`이며 시작 페이지는 `arcade-room.html`이다. 원래 게임의 시작 페이지와 빌드 설정은 유지한다.

- Node 테스트: 충돌·별 획득·보호 시간·종료·블록 회전·동시 줄 삭제·생성 막힘·최고 기록 격리·저장 실패.
- Node 테스트 6/6, 변경 JS ESLint 및 전용 Vite 프로덕션 빌드 통과.
- Chrome 첫 화면, 드라이브 이동·일시정지·충돌 종료·재도전·새로고침 후 최고 기록 복원 확인.
- 390×844 모바일에서 공방 이동·회전·내려놓기 버튼 확인. 가로 넘침 없이 모든 조작 버튼이 첫 화면 안에 표시된다.
- 공방의 쌓임 종료·결과 표시, 두 게임의 독립 기록 복원 확인. 검증 중 앱 콘솔 오류 없음.
- 로컬 배포용 미리보기 `http://127.0.0.1:4326/arcade-room.html`에서도 캐릭터 로딩, 공방 시작·키보드 이동·회전·내려놓기·소리 토글·일시정지 확인. 이 주소는 로컬 서버이며 운영 공개 URL이 아니다.
