# 작은 오락실: 이어하기와 다섯 스테이지

## 범위와 디자인

기존 바닷가 오락실과 SimCity풍 원본 캐릭터를 유지한다. 종이색 `#fff9e9`, 잉크색 `#234454`, 민트 `#92bfb3`, 복숭아 `#eab19b`, 노랑 `#f5d77e`, 기존 Jua/Noto Sans KR 조합을 사용한다. 캐비닛에는 완료 도장과 1~5단계 선택, 게임에는 목표 표시를 추가한다. 조작 버튼은 기존 위치에 유지한다.

한 판은 최대 60초이며 목표를 채우면 즉시 클리어한다. 실패해도 열린 단계는 유지되고 같은 단계에 다시 도전한다. 이미 완료한 단계는 홈에서 다시 선택할 수 있다. 이어할 판이 있으면 먼저 이어하기 또는 일시정지 화면의 다시 시작으로 처리한다.

| 게임 | 1 → 5단계 목표 |
| --- | --- |
| 원이 드라이브 | 별 3 / 5 / 7 / 9 / 12개 |
| 메이 조각 공방 | 2 / 3 / 5 / 7 / 10줄 |
| 제나 포토부스 | 성공 사진 5 / 8 / 12 / 16 / 20장 |
| 미나미 댄스 | 박자 성공 12 / 20 / 28 / 36 / 45회 |
| 리브 별빛 산책 | 별 8 / 14 / 20 / 26 / 32개 |

1단계는 기존 속도를 유지한다. 단계마다 이동·낙하·박자 속도 배율이 0.12 증가하며 5단계는 1.48배다. 사진 및 리듬의 성공 판정 폭도 좁아진다. 기존 한 판 안의 점진적인 난이도 상승은 함께 적용한다. 목표 및 난이도 수치는 첫 플레이 검증용이며 장기 이탈/완주 데이터에 따른 균형 조정은 별도다.

## 저장 계약

`rescene.arcade.journey.v1`에 멤버별 열린 단계, 완료 단계, 단계 최고점, 진행 중인 판을 저장한다. 기존 최고점 키 `rescene.small-arcade.v1`은 보존한다. 플레이 중 약 1초마다 저장하며 일시정지·화면 숨김·페이지 이탈·클리어 시에도 저장한다. 브라우저 강제 종료 직전에는 마지막 자동 저장 이후 약 1초가 손실될 수 있다.

블록 위치와 다음 조각, 남은 시간, 점수, 판정 상태 및 난수 상태까지 복원한다. 재접속 시 일시정지 상태로 열어 사용자가 계속하기를 누르기 전 시간이 흐르지 않는다. 손상된 저장은 해당 판만 무시하며 완료 단계는 연속된 단계만 인정한다. 저장 불가 시 경고하고 현재 탭 메모리에서만 진행한다. 계정/클라우드 동기화는 없으며 사이트 데이터 삭제 시 기록도 지워진다.

## 멤버 반응과 음성

기존 `public/arcade-room/town-cast.webp`는 수정하지 않는다. 새 `cast-reactions.png`는 원본을 참조해 이미지 생성 도구로 만든 투명 5열 스프라이트다. 원본 열 순서인 원이·리브·미나미·메이·제나를 유지한다. 성공 시 약 1.1초 보여 주며 클릭/터치 입력을 가리지 않는다. OS 동작 줄이기 설정에서는 확대·회전 없이 포즈만 표시한다.

- 원이: 주먹 응원 / “좋아, 다음 길도 같이 가자!”
- 메이: 한 줄 제거 시 윙크와 브이 / “클리어는 그립갑이 좋다”
- 제나: 볼꽃 포즈 / “이 순간, 저장 완료! 찰칵!”
- 미나미: 댄스 브이 / “우리 호흡, 딱 맞았어!”
- 리브: 손하트 / “반짝이는 오늘, 함께 간직하자!”

메이 문구는 사용자가 제공한 표기를 그대로 사용했다. 나머지 문구와 포즈는 **임시 창작안**이며 실제 멤버의 공식 유행어·시그니처라고 확인된 자료가 아니다.

실제 멤버 녹음은 제공되지 않았다. 사용자가 합성 음성을 켜면 클리어 시 브라우저 한국어 음성으로 멘트를 재생한다. 결과 화면에서 다시 듣기도 가능하다. ‘임시 합성 음성 · 실제 멤버 녹음 아님’을 명시하며 게임 시작·홈 이동·일시정지 시 발화를 취소한다. 한국어 음성의 품질과 제공 여부는 브라우저/OS에 따라 다르며 실패해도 자막과 게임 진행은 유지한다. 실제 녹음 연결과 멤버별 실제 유행어 확정은 남아 있다.

이미지 생성 방향: 원본의 얼굴, 머리, 의상과 둥근 장난감 같은 재질을 유지하고, 동일 크기의 전신 5열에 각 성공 포즈를 한 개씩 배치한다. 텍스트·배경·바닥·그림자 없이 투명 배경으로 생성한다. 새 포즈 원본은 Git 자산으로 포함하며 런타임에 투명 여백을 잘라 기존 캔버스에 그린다.

## 검증

노드 테스트: 다섯 게임 저장/복원 및 난수 연속성, 단계 해금/재도전/최종 단계, 손상 저장/저장 실패/기존 최고점 보존, 난이도 증가.
브라우저 테스트: 새로고침 후 일시정지 복원, 메이 한 줄 윙크, 2줄 클리어와 다음 단계, 합성 음성 호출(스텁), 실패 시 미해금 및 다른 멤버의 진행 보존. 기존 다섯 게임 조작·일시정지·결과·모바일 레이아웃 검증도 함께 실행한다. 실제 멤버 음성 또는 실기기 검증 완료를 뜻하지 않는다.
