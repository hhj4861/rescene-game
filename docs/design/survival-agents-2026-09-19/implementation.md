# 로컬 서바이벌 구현 및 검증

작업 브랜치: `feat/survival-local-agents-20260919`. 기존 아트·동네 변경에 의존하지 않는 별도 진입점이다. 기준 브랜치 머지는 사용자 승인 전 수행하지 않는다.

## 실행

```sh
node server/survival/server.mjs
# http://127.0.0.1:4317/survival.html
node --test tests/survival/*.test.mjs
node tools/survival/verify-browser.mjs
# 실제 모델 사용량이 발생하는 두 라운드 검증
node tools/survival/verify-live.mjs --live
```

브라우저 검증은 기존 package.json의 @playwright/test를 사용한다. 의존성이 다른 checkout에 설치돼 있으면 `SURVIVAL_DEPENDENCIES`로 그 경로를 지정한다. 서버 자체는 Node 표준 라이브러리만 사용한다. 저장 위치 기본값은 OS 임시 폴더의 `rescene-survival-local/season.json`이며 `SURVIVAL_DATA_DIR`로 영구 보관할 전용 디렉터리를 지정할 수 있다. 임시 폴더는 OS가 삭제할 수 있으므로 장기 보관용이 아니다. 포트는 `SURVIVAL_PORT`로 지정한다. 서버는 루프백에만 바인딩하고 Origin/Host/요청 토큰을 검증한다.

## 구현 범위

- 플레이어+5멤버 공동 제안/토론/투표, 합계12 연습 배분과 파트/음악/안무 선택, 4/6 합의와 유저 반대 재토론.
- 20팀/10라운드 자동 컨셉, 고정 시드 대진, 패자 중 하위2 탈락과 2팀 결승. 상대 팀은 규칙 기반 계획이며 모든 팀을 같은 다섯 LLM 심사위원이 평가한다.
- 다섯 멤버의 독립 수행 의도, 결정적 게임 증거, 다섯 전문가의 전팀 배치 심사. 음원 분석이 아닌 시뮬레이션 평가다. 무대 리플레이와 직접 합성한 짧은 신스 스케치를 제공한다.
- 멤버별 출처/기억 격리, 근거 있는 회고/행동 가설, 감소효용 숙련 성장, 디스크 저장 후 재시작. 모델 가중치를 재학습하지 않는다.
- 역할별 실제 Claude/Codex CLI 호출. 두 제공사 합산 동시2, 정확한 세션 ID, 24,000 입력토큰 이상이면 새 문맥. 심사위원은 항상 라운드별 신규 문맥. 오류 응답을 정해진 대사로 대체하지 않는다.
- 명령 ID/리비전 검사, 호출별 완료 체크포인트, 부분 실패 재시도, 실제 자식 종료 확인 후 취소. 기본30/정상50/실패 포함55회, 개별1회 및 라운드5회 재시도 상한. 예산 소진 시 중단하며 현재 UI에서 추가 예산 발급은 지원하지 않는다.
- 플레이어 탈락 후 공식 관전도 동일한 심사5회/라운드를 명시하고 실행한다.

## 공동 리뷰에서 수정한 계약

Claude `20260919074116130-7a1708`의 B1~B5를 수용했다. 심사위원의 이전 점수 문맥 누적 금지, 개발 저장소 밖 역할별 cwd, Claude 빈 tools/strict MCP, 제공사 합산 동시성, JSON 스키마 및 출처/기억/증거 참조 검증을 적용했다. 사용자 전역 훅·승인·인증은 우회하지 않는다. Claude는 구현 파일을 수정하지 않고 읽기 전용 리뷰를 맡는다.

Codex는 사용자 config의 플러그인/MCP/앱 **이름만** 읽어 해당 호출에서 비활성화한다. 쉘·실행·웹·멀티에이전트 등도 제한하고 read-only sandbox를 유지한다. 인증정보를 복제하지 않는다. Codex CLI가 설정 키의 따옴표를 경로 일부로 해석하는 실패를 실제 확인해 안전한 키 이름만 전달하도록 수정했다. 이 환경에서 `code_mode_host=false`의 의도적 fail-closed 안내가 발생할 수 있다. 실행 중 도구 호출 이벤트가 감지되면 결과를 수락하지 않는다.
