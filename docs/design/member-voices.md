# 멤버 유행어와 원본 음성 연결

작성일: 2026-10-01. 사용자 승인 후 [PR #10](https://github.com/hhj4861/rescene-game/pull/10)을 머지하고 [운영 게임](https://rescene-arcade.pages.dev/)에 배포했다. 소스는 `93b2726`, Pages 배포는 `f7037308-48c8-4ca7-b1d8-d81aa2338069`이며 검증 기록은 [배포 문서](../deployment/arcade-pages.md)에 정리한다.

**후속 장애 확인:** 위 배포의 MP3 다섯 개는 디코딩과 재생 시간 진행은 정상이나 실제 신호가 무음이었다. 당시 테스트 통과는 음성의 가청성을 증명하지 못했다. 아래 수정은 `feat/arcade-five-games-endless-20261001` 브랜치에 있으며 아직 운영 배포 전이다.

## 무음 수정

기존 추출 명령에서 출력 시점 탐색과 페이드 필터의 시간 기준을 잘못 조합해, 선택한 구간이 나오기 전에 페이드가 끝났다. 다섯 MP3 모두 `volumedetect`의 평균·최대가 -91.0 dB였다. 원본 영상 구간에는 평균 -20.8 dB, 최대 -1.9 dB의 소리가 남아 있었다.

동일한 원본·발언 구간에서 `atrim → asetpts=PTS-STARTPTS → afade` 순서로 다시 추출했다. 음성 자산 URL에 `?v=2`를 붙여 이전 무음 캐시를 피한다. 새 녹음이나 합성 음성을 추가하지 않았다.

| 수정 파일 | 평균 dB | 최대 dB |
| --- | ---: | ---: |
| 원이 | -16.0 | 0.0 |
| 메이 | -19.0 | -1.6 |
| 제나 | -20.2 | -1.8 |
| 미나미 | -20.0 | 0.0 |
| 리브 | -16.8 | 0.0 |

브라우저 테스트에 실제 배포 MP3를 디코딩한 샘플의 peak > 0.01, RMS > 0.001, 유효 샘플 비율 > 10% 검사를 추가했다. 재생 시간만 진행하는 무음 파일은 이제 실패한다. 이 검사는 직접 청음이나 스피커 음질 검수를 대신하지 않는다.

## 플레이 흐름

- 기존 캐릭터·메이 줄 완성 윙크·진행 저장·스테이지 난이도는 유지한다.
- 클리어 자막을 수집한 유행어와 게임용 각색으로 교체한다. 메이의 `그립갑`은 `그립감`으로 수정한다.
- `멤버 음성 켜기`는 해당 멤버의 원본 녹음을 미리 재생하며, 켜 둔 동안 이후 클리어에서도 재생한다. 기본은 꺼짐이며 설정은 현재 탭에만 유지된다.
- 결과 화면에서는 설정과 관계없이 실제 음성을 직접 듣고 정지할 수 있다. 새 재생은 이전 재생을 취소한다.
- 다음 스테이지·홈·일시 정지·탭 전환·페이지 이탈 시 음성을 정지한다. 결과 화면에서도 탭 전환 시 정지한다.
- 재생이 거부되거나 파일을 불러오지 못하면 다시 듣기 안내를 표시한다. 게임 진행·저장·잠금 해제는 오디오와 독립적이다. 합성 음성으로 몰래 대체하지 않는다.
- 원본 발언과 다른 게임 문구는 `게임용 각색`으로 표시한다. 결과 창에는 원본 문구·출처 링크를 제공한다.

## 자산과 출처

[MBCentertainment 공식 유튜브의 유행어 소개](https://www.youtube.com/watch?v=pWTBJV0OrqU)에서 짧은 발언만 발췌했다. 원본 영상 전체나 자막 전문은 Git에 넣지 않았다. 방송 배경음·웃음이 포함된 **실제 녹음 발췌**이며, 공식 게임용 신규 녹음 또는 음성 복제가 아니다. 공개 영상이라는 사실을 별도의 게임용 라이선스 취득으로 표시하지 않는다.

| --- | --- | --- | --- | --- |

MP3 96kbps, 44.1kHz, mono. 가장자리 15ms/40ms 페이드만 적용했다. 말 순서·피치·속도 변경이나 발언 합성은 없다. 파일 합계 약 154KB. 실행 시 YouTube나 AI API에 요청하지 않고 게임 정적 자산을 재생한다.

## 검수 근거와 한계

- 기존 공개 자동 자막, 공식 영상의 해당 장면·화면 자막을 대조했다. 화자가 바뀌는 소개 장면과 메이 이름 자막도 확인했다.
- 외부 API 없이 로컬 Whisper base로 음성 구간을 추가 전사했다. 자동 인식에는 사투리·유행어 오인식이 있어 화면 자막의 대체 근거로 사용하지 않는다.
- 화면·자막·파일 재생/디코딩 검증을 직접 청음이나 실제 iPhone 스피커 음질 검수라고 표시하지 않는다. 최종 말끝·청감은 사용자 미리듣기로 확인할 수 있다.
- 음성을 먼저 켜도 브라우저 정책이 자동 재생을 막을 수 있다. 이 경우 클리어의 다시 듣기 버튼으로 직접 재생한다.

작업 원본·프레임 모음·로컬 전사·빌드·테스트 산출물은 사용자 지정 iCloud 작업 루트의 `rescene-game/member-voices-20261001/`에 둔다. 자산과 구현 소스는 로컬 Git worktree에서 관리한다.

## 검증

- 단위 테스트: 중복 재생 취소, 오래된 콜백 차단, 재생 거부·미디어 오류 처리, 종료 시 자원 해제, TTS 미사용.
- 브라우저 테스트: 다섯 멤버의 실제 MP3 디코딩/재생 시간 진행, 클리어 자막·출처 연결, 다시 듣기·정지·다음 스테이지 이동, 기본 무음, 파일 실패 후 진행, 결과 창 포커스와 백그라운드 정지.
- 로컬 검증 결과: 단위 테스트 29개, 전체 브라우저 테스트 69개(데스크톱 Chromium·모바일 Chromium·모바일 WebKit), 린트·빌드 모두 통과.
- 처음 검증에서 WebKit의 출처 링크 다음 포커스 이동 실패를 발견해 결과창의 Tab 순환 처리를 수정했고, 위 전체 테스트에서 통과했다.
- 브라우저 캡처에서 기존 메이 캐릭터와 각색/원본 구분·듣기·정지·출처 표시를 확인했다. 실기기 청음 테스트는 수행하지 않았다.
