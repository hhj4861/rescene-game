# 목숨으로 이어가는 무한 스테이지

작성일: 2026-10-01. 구현 브랜치 `feat/arcade-five-games-endless-20261001`에서 검증하며, 머지·운영 배포 전이다.

## 플레이 규칙

- 멤버별 새 도전은 스테이지 1, 목숨 3개로 시작한다. 기존 캐릭터와 시그니처 반응을 유지한다.
- 목표를 달성하면 멤버의 클리어 화면을 보여 주고, ‘다음 스테이지’로 계속한다. 5단계 종료 제한을 없앴다. 목숨은 다음 단계에 그대로 이어진다.
- 각 단계의 제한 시간은 60초다. 시간 초과 또는 조각 공방의 보드가 가득 차면 목숨 하나를 잃고 같은 단계에 재도전한다.
- 드라이브는 충돌, 포토부스는 촬영 실패, 리듬 게임은 놓친 노트, 별 받기는 놓친 별마다 목숨 하나를 잃는다. 리듬의 너무 이른 입력은 콤보만 초기화하고 해당 노트를 실제로 놓쳤을 때 목숨을 차감한다.
- 목숨이 0이면 GAME OVER다. 새 도전은 스테이지 1과 목숨 3개로 시작하며 최고 도달 단계와 기존 점수 기록은 유지한다.
- 일시 정지의 ‘스테이지 1부터 새 도전’도 같은 규칙이다. 현재 높은 단계에서 무료로 목숨을 채우는 재시작은 제공하지 않는다.

## 난이도와 저장

1~5단계의 속도·목표는 기존 값을 유지한다. 6단계부터 속도는 매 단계 증가하되 3배에 점진적으로 접근한다. 목표도 게임별 한도에 접근하도록 늘려 60초 안에 요구하는 양이 무한히 커지는 일을 방지한다. 목표 수가 같은 연속 단계에서도 속도는 증가한다. 리듬 판정 시간에는 하한을 적용한다. 정수 표현의 기술적 한도 외에 게임의 마지막 단계는 없다.

저장 키 `rescene.arcade.journey.v1`은 유지하고 내용의 버전을 2로 올린다. 각 게임의 현재 단계, 최고 도달 단계, 남은 목숨, 진행 중 상태를 브라우저에 저장한다. 게임 오버 상태도 저장하므로 새로고침이 높은 단계의 목숨을 충전하지 않는다. 브라우저 저장이 거부돼도 현재 탭에서는 진행한다.

기존 버전 1의 연속 클리어 기록을 새 단계로 옮긴다. 다섯 단계를 모두 완료한 저장은 6단계에서 시작한다. 유효한 진행 중 저장은 보드·시간·점수·기존 목숨을 복원한다. 과거에 목숨 항목이 없던 게임에는 3개를 부여한다. 멤버별 최고 점수의 기존 저장 키는 변경하지 않는다.

## 검증 범위

- 모델·저장 테스트: 30단계 연속 클리어, 단계 10,000까지 속도 증가와 유효한 리듬 판정, 게임별 목숨 소진, 중복 차감 방지, 실패 후 같은 단계, 이전 저장 이관, 게임 오버 복원, 최고 단계 유지.
- 브라우저 테스트: 5→6단계와 남은 목숨 유지, 클리어 직후 새로고침, 세 번 실패 후 종료, 재도전·새로고침의 목숨 유지, 새 도전과 최고 단계 기록.
- 오디오 수정과 검증은 [멤버 음성 문서](member-voices.md)에 기록한다.
- 테스트 산출물: 사용자 지정 iCloud 작업 루트의 `rescene-game/endless-20261001/`.

로컬 검증 결과: 단위 테스트 39개, 린트·빌드 통과. 브라우저 78개 중 첫 실행에서 72개가 통과했고, 변경된 재도전 버튼명을 반영하지 않은 6개가 실패했다. 해당 테스트를 수정한 뒤 배포 검증 12개를 세 브라우저에서 재실행해 모두 통과했다. 데스크톱·모바일 WebKit의 6단계 캡처에서 기존 캐릭터, 남은 목숨 2개와 조작 버튼 배치를 확인했다.

실제 장시간 플레이의 체감 난이도와 실기기 스피커 청음은 자동 검증 범위에 포함하지 않는다.
