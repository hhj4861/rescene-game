# 작은 오락실 — 남은 확인

2026-09-30. 자동 검증과 사람이 확인할 항목을 구분한다. 아래 참여자 테스트와 실제 기기 확인은 아직 수행하지 않았다. 배포 빌드의 하위 경로·터치·화면 크기 전환·저장 차단·포커스 상실을 브라우저 회귀 검사에 추가했다. 실제 기기의 주소창·잠금·오디오 지연은 이 검사로 확인됐다고 간주하지 않는다.

## 짧은 이용자 테스트

게임 숙련도가 다른 3~5명에게 휴대폰으로 첫 화면을 보여준다. 설명을 먼저 읽어주지 않는다.

1. 원하는 멤버를 골라 한 판 플레이하게 한다. 시작까지 걸린 시간, 첫 조작, 도움 요청 지점을 적는다.
2. 결과 화면에서 다음 행동을 자유롭게 고르게 한다. 재도전·다른 멤버·종료 중 무엇을 골랐는지 기록한다.
3. 가장 편했던 게임과 어려웠던 게임, 기억나는 멤버 이름을 묻는다. 점수가 낮다는 이유만으로 실패한 체험이라고 판단하지 않는다.

첫 조작까지 10초 이내, 도움 없이 한 판 완료, 결과에서 다음 행동을 이해하는 것을 초기 관찰 기준으로 삼는다. 이는 검증된 수치가 아니라 이번 테스트에서 조정할 가설이다. 결과에 따라 속도·판정 폭·안내 문구를 조정한다.

## 실제 기기

- iPhone Safari / Android Chrome: 시작, 버튼 누르기·떼기, 드래그, 스크롤, 화면 회전, 주소창 확장/축소.
- 320px 폭의 작은 화면: 메이의 다음 조각과 모든 조작 버튼, 결과 대화상자 접근.
- 앱 전환·화면 잠금 후 복귀: 시간 정지, 버튼이 눌린 채 남지 않음, 이어하기.
- 미나미: 소리 OFF/ON, 이어폰/스피커, 보정 -200/0/+200ms를 사용자가 이해하는지 확인.
- 게임별 완료·재도전·새로고침 후 기록 복원. 저장 불가 환경에서 결과 안내.

## 공개 주소 자동 검증

`Arcade live checks`는 로컬 서버 대신 `https://rescene-arcade.pages.dev/`에서 다섯 게임의 시작·입력·일시정지·종료·재도전·기록 복원과 기존 배포 회귀 검사를 실행한다. 데스크톱 Chromium·모바일 Chromium·모바일 WebKit에서 각각 검사한다. 브라우저가 받은 HTML·게임 코드·스타일·캐릭터 파일의 SHA-256도 현재 checkout의 빌드와 비교하여 구버전 배포를 통과시키지 않는다.

배포된 코드와 일치하는 커밋에서 수동 실행한다. 공개 서비스에 아직 배포하지 않은 게임 코드 변경은 해시 비교에서 실패하는 것이 정상이다. 인증정보와 배포 단계는 없으며 테스트별 브라우저 저장소는 격리된다. 실제 휴대폰·사람의 재미/난이도 확인은 대체하지 않는다.

로컬 실행 명령은 `npx playwright test --config playwright.live.config.js`이며 `ARCADE_TEST_OUTPUT`과 `ARCADE_BUILD_OUTPUT`은 작업별 산출물 경로를 지정한다. CI 화면·실패 trace·파일 해시 증거는 `arcade-live-verification` 산출물로 7일 보관한다.
