# 다섯 멤버의 작은 오락실

2026-09-30. 첫 두 게임의 PR #5를 main에 머지한 뒤, 나머지 세 게임과 공통 조작 개선을 별도 구현 브랜치에 추가했다. 운영 배포는 아직 하지 않았다.

## 대상과 목적

잠깐 쉬는 시간에 휴대폰으로 멤버 캐릭터와 놀고 싶은 사람을 대상으로 한다. 설명을 외우거나 계정을 연결하지 않고 첫 행동을 시작하는 것이 목표다. 한 판은 최대 60초이며, 결과에서 재도전 또는 다음 멤버로 바로 이동한다. 재도전율·조작 이해도·멤버 친숙도는 기대효과 가설이며 실제 이용자 검증이 필요하다.

## 게임과 조작

| 멤버 | 게임 | 기본 행동 | 종료 |
|---|---|---|---|
| 원이 | 바닷길 드라이브 | 좌우 이동·길 터치로 장애물을 피하고 별 수집 | 60초 또는 세 번 충돌 |
| 메이 | 조각 공방 | 좌우·회전·내려놓기로 한 줄 완성 | 60초 또는 조각을 놓을 공간 없음 |
| 제나 | 깜짝 포토부스 | 불빛이 중앙에 올 때 찰칵 버튼 또는 Space | 60초 |
| 미나미 | 댄스 타임 | 음표가 선에 닿을 때 같은 쪽 버튼·방향키·A/L | 60초 |
| 리브 | 별빛 산책 | 좌우·별길 터치/드래그로 떨어지는 별 받기 | 60초 |

제나는 중앙에서 ±0.05 이내면 완벽, ±0.15 이내면 성공이다. 촬영 간격은 0.65초이며 최근 사진 다섯 장을 보여준다. 미나미는 ±220ms 안의 같은 쪽 입력을 판정하고 ±90ms를 완벽으로 처리한다. 도움말의 -200~200ms 보정값은 이 브라우저에 저장한다. 리브의 일반 별은 100점, 파란 별은 200점이다. 새 세 게임은 실패해도 즉시 종료하지 않는다.

## 디자인과 공통 흐름

- 기존 심시티 캐릭터 아틀라스를 유지했다. 파일: `public/arcade-room/town-cast.webp`; SHA-256: `ef088f158ecc228e3c72ee0207fc97c62503d9b95b6c3a2dec9e72b29baad888`. 열 순서는 원이·리브·미나미·메이·제나다.
- 바닷가 오락실·종이색 배경·둥근 기계를 유지하고 민트·피치·로즈·라일락·하늘색으로 게임을 구분한다. 화면에는 멤버 이름과 게임 이름을 함께 표시한다.
- 다섯 기계에서 즉시 시작한다. 모바일에서는 한 열로 배치하고 조작을 게임판 바로 아래에 둔다. 메이의 다음 조각은 모바일에서도 게임판 위에 표시한다.
- 메이의 좌우 버튼은 누르고 있으면 반복 이동하며 손을 떼거나 포커스를 잃으면 멈춘다. 이벤트마다 기존 캐릭터 포즈와 짧은 창작 대사가 반응한다.
- 일시정지·도움말·탭 전환·창 포커스 상실은 게임 시간을 멈춘다. 완료 시 기록 저장 → 재도전/다음 멤버/오락실 흐름을 제공한다. 중도 종료 점수는 저장하지 않는다.
- 최고 기록은 `rescene.small-arcade.v1`에 게임별로 저장한다. 기존 두 게임 기록을 유지하며 새 세 게임은 0으로 시작한다. 저장 차단 시에도 게임은 동작하고 결과에서 저장 실패를 알린다.
- 효과음은 기본 OFF이며 직접 합성한 음만 사용한다. 실제 음원·목소리는 사용하지 않는다. 게임 중 AI 호출·로그인·네트워크 점수 전송은 없다. JEV는 보류한다.

## 검증 구분

Node 테스트는 기존 여섯 검사와 새 여섯 검사로 구성된다. 충돌·회전·줄 삭제·사진 판정·리듬 입력 중복/보정·별 획득·60초 종료·기록 이관·저장 차단을 검사한다. 로컬에서 12개 통과, ESLint와 프로덕션 빌드 통과를 확인했다.

Playwright는 데스크톱 Chromium, 모바일 Chromium, 모바일 WebKit에서 시작·입력·일시정지·종료·재도전·기록 복원과 작은 화면·반복 이동·리듬 보정을 검사한다. [CI 실행 36686784184](https://github.com/hhj4861/rescene-game/actions/runs/36686784184)에서 24개 통과와 Node 12개·린트·빌드 통과를 확인했다. 이후 변경의 실제 성공 여부는 PR의 최신 `Arcade checks` 결과를 따른다. 첫 화면과 각 게임 화면도 CI 산출물에 저장한다.

실제 휴대폰의 오디오 지연·제스처와 이용자의 재미/난이도는 별도 [플레이테스트](arcade-playtest.md)로 확인한다. 로컬 미리보기·CI 정적 빌드는 운영 공개 배포와 다르다.
