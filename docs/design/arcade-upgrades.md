# 아케이드 아이템·조작 개선

기존 승인 캐릭터와 오락실 레이아웃을 유지한다. Jua는 게임 제목·수치, Noto Sans KR은 조작 설명에 사용한다. 색은 기존 잉크 #244655, 종이 #fff8e8, 메이 보라 #917d98, 리브 밤하늘 #213e58, 강화 민트 #8dccc0, 보상 별빛 #fff3a8을 사용한다. 새 UI는 플레이판 위쪽의 짧은 효과 표시와 조작 버튼의 키 표시에 집중한다. 아이템은 색뿐 아니라 기호·이름으로 구분하고, 모바일 버튼과 키보드 포커스를 유지한다.

- 메이: 적을 터뜨리면 이동 속도/방울 크기 아이템을 번갈아 떨어뜨린다. 획득하면 10초간 강화하며 중복 획득은 시간만 갱신한다.
- 리브: + 게이트는 연사 강화(최대 5단계), × 게이트는 탄 수 증가(최대 5발). 보스 처치를 스테이지 클리어 조건으로 둔다. 응원봉(피해 증가), 음표 요정(추가 탄), 별똥별(주기적 전체 공격), 오로라 날개(세 길 사격)는 10초 동안 적용한다.
- 원이: 단계별 속도·가짜 확률을 연속적으로 높이되 상한을 둔다. 8단계부터 가짜 최대 2마리. 후반 가짜는 원래 색에 가까워지지만 × 표식은 항상 유지한다.
- 제나: 드래그 도중 빵이 손을 따라 움직여 교환 방향을 보여준다. 밀대는 처음 1개, 연쇄 3회 충전마다 1개(최대 2개). 선택한 줄 제거와 낙하를 기존 연쇄 시스템으로 처리한다.
- 모든 게임: 기존 키보드 조작을 검증하고 표시한다. 아이템 획득 음성은 기존 멤버 녹음과 음소거 설정을 사용한다.

목숨 회귀 재현: 기존 브라우저 빌드에서 리브 적 3마리 동시 통과는 목숨 3→0, 메이 충돌+시간 초과는 3→1로 재현됐다. 1.4초 피해 보호를 저장하고 중복 차감을 막는다. 한 번의 실패 이후 별개의 실패는 보호 시간 종료 후 다시 차감한다.

작업 브랜치 구현이며 아직 운영 배포되지 않았다.

## 검증

- Node 모델 검사 53개 통과, ESLint 및 프로덕션 빌드 통과.
- Chromium 데스크톱·Pixel 7·iPhone 13 WebKit: 전체 163개 통과/환경 전용 5개 제외. 추가 원이·제나 아이템 음성/키보드 검사 6개 통과. 총 고유 성공 169개.
- 음성은 실제 MP3 미디어 요소의 재생 시간과 멤버별 URL로 확인. 기존 5명 녹음 디코딩 검사, 음소거·중단·저장 복원 검사도 통과.
- 데스크톱·모바일 캡처에서 캐릭터 보존, 효과 시간 표시, 리브 보스, 제나 낙하 및 드래그 미리보기, 원이 후기 × 표식을 확인.
- 리브의 1/5/10/50/1000단계는 입력 시뮬레이션으로 60초 안에 보스 처치 가능함을 확인. 사람이 느끼는 재미와 실제 기기 터치 감각 검증을 대신하지 않는다.
- 검증 자료: 공용 iCloud 작업 루트의 `rescene-game/may-powerups-20261003/`. `baseline-e2e`는 의도적으로 실패한 수정 전 목숨 재현, `final-browser`와 `item-voice-browser`는 수정 후 성공 증거다.

CI 37081671830에서 168개는 통과했지만 Safari의 ResizeObserver 오류 1건이 검출됐다. 크기 감지 콜백의 선택/스크롤 처리를 다음 프레임으로 옮기고, 화면 회전 중 중간 스크롤 위치가 선택을 바꾸지 않도록 보완했다. 세 브라우저의 화면 회전·선택 유지·진입/복귀·음성 회귀 검사 31개가 통과했다(환경 전용 2개 제외). 새 회전 시나리오 3개를 포함한 총 고유 로컬 성공 수는 172개다. 제나의 대각선 드래그 무반응도 `baseline-drag`에서 수정 전 실패를 비교 확인했다.

후속 CI 37082632816에서 171개 통과 후 같은 WebKit 경고가 회전 스트레스 시나리오에서 재현됐다. 최종 구현은 viewport에만 의존하는 캐비닛 너비에 맞춰 ResizeObserver 대신 window resize 이벤트에서 다음 프레임에 정렬한다. 회전·음성 검사는 통과했지만 초기 레이아웃 폭 변화로 가로 스크롤 선택 1건이 실패했다. 크기 비교 기준을 레이아웃 요소 폭에서 실제 창 너비로 일치시켜 보완한다. 경고 필터·테스트 제외는 사용하지 않는다.

실제 창 너비 기준 보완 후 관련 31개 검사와 회전·가로 스크롤의 3브라우저 × 3회 반복 18개가 모두 통과했다. 최종 빌드 및 증거는 `viewport-final-build`, `viewport-final-browser`, `viewport-repeat`에 보존한다.
