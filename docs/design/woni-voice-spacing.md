# 원이 보상 음성 간격

원이 금빛 파이리를 연속해서 잡을 때 같은 “오이쉬에~” 녹음이 매번 재시작되던 문제를 수정한다.

- 금빛 획득 자동 음성은 최소 15초 간격으로 재생한다. 재생·준비 중인 음성을 끊거나 대기열에 쌓지 않는다.
- 음성이 생략돼도 점수, 아이템 획득 수, 효과음, 캐릭터 반응은 그대로 적용한다.
- 간격은 현재 탭의 일시정지·홈 이동·스테이지 전환에서도 유지한다. 다시 로드하면 간격은 초기화되지만 이미 저장된 획득 음성을 소급 재생하지 않는다.
- 마지막 금빛 획득으로 클리어하면 보상 음성을 따로 요청하지 않고 클리어 음성 한 번만 재생한다. 클리어 음성과 수동 다시 듣기는 15초 보상 제한을 받지 않는다.
- 다른 멤버의 보상 음성 정책은 유지한다. 새 음원은 추가하지 않는다.

2026-10-03 사용자 승인 후 PR #18을 머지하고 [운영 게임](https://rescene-arcade.pages.dev/)에 배포했다. 소스는 `424624f5c1f100de3c61eb24d75b3116409f24f6`이며 [배포 기록](../deployment/arcade-pages.md)에 증거를 남겼다.

검증: Node 55개, ESLint, 프로덕션 빌드 통과. 데스크톱 Chromium·모바일 Chromium·모바일 WebKit에서 전체 브라우저 175개 통과, 환경 전용 5개 제외. 실제 MP3 재생과 15초 간격·일시정지·점수/획득 수 유지·마지막 금빛 중복 방지·수동 다시 듣기를 확인했다. 증거는 공용 iCloud 작업 루트 `rescene-game/woni-voice-spacing-20261003/browser-final.log` 및 `browser-final/`에 저장했다.

운영 검증: 공개 주소에서 전체 브라우저 175개 통과/환경 전용 5개 제외, 공개 파일 12개 해시 일치. PR CI 37114027495와 머지 후 main CI 37114525205 모두 성공했다. 운영 증거는 `rescene-game/woni-voice-deploy-20261003/`에 보관한다.
