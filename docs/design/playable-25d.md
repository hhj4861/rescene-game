# 승인 캐릭터의 본게임 연결 — 2026-09-29

승인된 2.5D 미리보기의 이미지 자산을 그대로 재사용해 실제 생존 시즌 게임에 연결했다. 독립 미리보기는 `/character-review.html`, 본게임은 `/survival-25d.html`이다. 기존 `/`, `/survival.html`, `/survival-3d.html`도 같은 본게임을 제공한다.

## 최종 멤버 연결

| 시안 | 멤버 ID | 이름 | 외형 |
|---|---|---|---|
| 01 | woni | 원이 | 검은 웨이브, 머리띠 |
| 02 | may | 메이 | 밝은 단발, 윙크 |
| 03 | zena | 제나 | 붉은 긴 웨이브 |

| 05 | liv | 리브 | 검은 긴 생머리, 윙크 |

원본 얼굴은 `public/assets/characters25/reference.png`에서 직접 표시하고 전신은 승인된 투명 아틀라스 `cast.png`를 표시한다. 이번 연결 작업에서는 두 이미지 파일을 수정하지 않았다. 아틀라스 제작 출처와 원본 대비 차이는 같은 폴더의 `provenance.json`에 기록되어 있다.

## 동작

- 첫 만남, 멤버 대화, 연습·휴식 배분, 투표, 회고, 성장 기록, 시즌 엔딩에서 동일한 ID별 얼굴을 사용한다.
- 전신 선택과 얼굴 선택은 해당 멤버의 실제 제안·토론·회고 대화를 연다. 전체 보기와 선택 멤버 보기, 키보드 방향키/Home/End/1–5 선택을 지원한다.
- 공연은 기존 합의안·음원 재생 시계를 사용한다. 파트의 멤버 ID로 중앙 캐릭터와 위치를 계산하므로 게임 데이터 배열 순서와 그림 순서가 달라도 인물이 바뀌지 않는다.
- 기존 게임 데이터의 연습·휴식 배열, AI 공급자·키·모델 설정, 저장 형식은 유지한다. 배분표의 데이터 순서와 사용자가 합의한 공연 파트 순서는 시안 전시 순서와 별개다.
- 미세한 호흡 움직임, 시차, 바닥 그림자로 깊이를 표현한다. 동작 정지와 시스템의 동작 줄이기 설정을 지원한다. 관절 애니메이션·립싱크·새 표정 생성은 포함하지 않는다.

## 검증

`node --test tests/survival/*.test.mjs`: **48/48 통과**. 매핑·중복 SVG 클립·동일 전신 배율·ID 기반 공연 배치와 HTTP 자산 제공을 추가 검증했다. 변경 JS의 ESLint와 `git diff --check`도 통과했다.

Chrome에서 별도 테스트 서버 `node tools/survival/character-fixture.mjs`로 다음을 실제 UI 조작하여 확인했다. 이 서버는 명시적 고정 응답만 사용하며 실제 서비스에는 연결되지 않는다.

1. 원이 첫 제안 실패 후 부분 재시도, 다섯 캐릭터 선택 시 각각 올바른 얼굴과 멤버 대사.
2. 사용자 반대 후 재토론, 찬성 후 공연 진행.
3. 메이의 48–60초 파트 선택 시 02번 캐릭터가 중앙에 표시됨. 음원 시계 진행, 일시정지, 음량 조절.
4. 회고 저장·메이 팀 기억 등록·새로고침 후 라운드 복원.
5. 10개 라운드를 모두 진행해 회고를 저장하고 우승 엔딩 표시.
6. 390×844 모바일에서 다섯 전신·얼굴과 조작 버튼 확인, 문서 가로 넘침 없음. 검증 후 viewport 설정 원복.

실제 LiteLLM 설정을 읽는 별도 로컬 서버에서는 캐릭터 로딩과 시작 버튼 활성화를 확인했다. 이번 작업에서 실제 Gemini 응답 품질이나 공급자 호출 성공을 새로 검증하지는 않았다. 테스트 서버와 실제 서버의 저장소도 분리했다.
