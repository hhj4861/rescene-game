# 펌프 점수제 — 2026-10-04

미나미 펌프는 목숨 없이 60초 동안 점수를 쌓는다. 미스는 콤보만 초기화하며 이미 얻은 점수를 깎거나 플레이를 중단하지 않는다. 성공 개수 목표도 완주 조건에서 제거했다. 0점이어도 시간이 끝나면 무대를 완주하고 다음 단계에 도전할 수 있다.

홈·곡 선택·플레이·도움말·결과의 목숨 안내를 없애고 성공/MISS, 점수, 최고 콤보, 노트 적중률을 표시한다. 최고 점수와 선택 곡·진행 위치 저장은 유지한다. 기존 목숨 0~2개인 펌프 저장도 단계·점수·노트 진행을 유지한다. 저장 형식의 hearts는 이전 버전과의 호환을 위해 3으로 유지하며 펌프 판정에는 사용하지 않는다. 다른 네 게임의 목숨 규칙은 그대로다.

공식 5곡과 오리지널 연습곡 3곡의 무입력 완주, 콤보/점수, 이전 저장, 중복 정산을 단위 검사한다. 브라우저에서는 3회 초과 미스 후 계속 플레이, 새로고침 복원, 60초 결과와 최고 기록, 공식 영상 종료/다른 곡 선택을 검증한다.
