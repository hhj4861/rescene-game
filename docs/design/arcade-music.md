# 게임별 연주곡·펌프 박자·리브 진격대

2026-10-02 사용자 요청으로 구현했다. 작업 브랜치의 변경이며 PR 머지·운영 배포는 별도 승인 후 진행한다.

## 메이 방향 전환

기존 모델에는 발사 방향이 있었지만 캐릭터는 항상 같은 그림으로 표시됐다. 좌우 입력에 맞춰 게임 안 캐릭터를 반전하고 발사 방향 표시를 추가했다. X키 또는 ‘뒤돌기’는 이동 없이 반대쪽을 보게 하며, 진행 중인 이동 입력도 해제한다. 방울은 마지막으로 바라본 방향으로 발사된다. 좌우 이동·점프·방울·뒤돌기는 키보드와 터치 모두 지원한다.

## 자체 제작 BGM

사용자가 ‘게임별 자체 제작 연주곡’을 선택했다. `music.js`의 멜로디·화성·베이스·타악 패턴을 Web Audio로 연주하는 8마디 루프다. 외부 음원·리센느 곡·샘플·음성 합성을 사용하지 않는다. 스튜디오 녹음이나 보컬 곡은 아니다.

| 게임 | 곡 | BPM | 방향 |
| --- | --- | ---: | --- |
| 원이 | 반짝 꼬리 산책 | 132 | 빠르고 경쾌한 아케이드 리듬 |
| 메이 | 방울 위의 스텝 | 112 | 부드럽고 통통 튀는 멜로디 |
| 제나 | 오븐 앞 오후 | 96 | 느긋한 카페풍 연주 |
| 미나미 | Five Steps, One Stage | 120 | 드럼·베이스 중심의 댄스 연주 |
| 리브 | 별빛 전진 | 128 | 추진력 있는 전자음악 |

BGM은 기본 켜짐이며 별도의 BGM 버튼으로 끌 수 있다. 전체 ‘소리’ 스위치는 BGM과 효과음을 함께 제어하며, 멤버 음성은 기존 별도 설정을 따른다. 끈 설정은 현재 탭에서 게임을 바꿔도 유지한다.

게임 경과 시간과 Web Audio 시간 사이의 기준점을 잡고 0.2초 앞까지 예약한다. 프레임마다 기준점을 다시 만들지 않는다. 일시정지·홈·결과 화면에서는 예약된 음을 중단한다. 이어하기에서는 저장된 게임 시점에서 다시 연주하며, 긴 프레임 지연 시 지나간 음을 몰아서 재생하지 않는다.

## 음악에 맞춘 펌프

120 BPM의 동일한 박자 값을 곡과 채보가 공유한다. 4박 도입 후 첫 발판이 나오고, 1단계는 두 박마다, 2단계부터 매 박에 발판이 나온다. 3단계부터 동시 발판, 4단계부터 반 박 엇박이 추가된다. 임의 간격으로 채보 속도만 올리지 않는다. 후반 판정 창과 목표 수는 기존 단계별 난이도 체계를 따른다.

기존 판정 보정(-200~200ms)을 유지한다. 사용자가 누를 때 별도의 높은 판정음을 겹치던 동작은 제거해 곡의 박자를 들을 수 있게 했다. 일시정지에서는 곡과 채보가 함께 멈춘다. 무음 선택 또는 오디오 권한 실패가 게임 진행을 막지는 않는다.

## 리브 별빛 진격대

사용자가 확인한 ‘숫자 게이트 선택·병력 증가·자동 사격’ 방식으로 설치형 디펜스를 교체했다. 기존 캐릭터와 오락실 외곽 디자인을 유지한다. 세로로 내려오는 적·게이트와 아래쪽 대원 무리를 배치해 다음 선택이 보이게 한다. 기존 Jua 글꼴과 청록 `#83c0ba`, 짙은 파랑 `#213e58`, 크림 `#fff0c7`, 위험 게이트 분홍 `#dc9ca1`을 사용한다. 적 체력·게이트 연산·대원 수가 배경 장식보다 먼저 보이도록 한다.

- 좌우키·화면 길 터치·1~3키로 길을 선택한다. 사격은 자동이다.
- +와 × 게이트는 대원을 늘리고 - 게이트는 줄인다. 대원 수에 따라 공격력이 증가하며 최대 60명이다. 이동·시간 경과·버튼 연타만으로 대원이 늘지 않는다.
- 적 다섯 팀 격파 시에만 별빛 지원이 충전된다. 사용하면 충전을 모두 소비한다.
- 매 다섯 번째 적은 체력이 높은 적이다. 단계가 높아지면 체력·진행 속도·격파 목표가 증가한다.
- 적이 뒤로 빠져나가거나 게이트로 대원이 모두 사라지면 목숨을 잃는다. 기존 목숨 3개·무한 스테이지·진행 저장을 유지한다.

기존 리브 설치 보드와 이전 펌프 채보는 새 규칙으로 그대로 복원하지 않는다. 해당 게임의 단계·남은 목숨·최고 단계는 보존하고 현재 단계부터 새 규칙으로 시작한다. 새 리브 저장에는 대원·게이트·적·탄환·지원 충전이 포함된다.

## 검증 범위

단위 검사에서는 뒤돌기 후 양방향 적 포획, BGM 중복 예약·중지·재개, 음악 박자와 채보 일치, 게이트 1회 적용, 대원 감소·목숨, 지원 충전 제한, 자동 사격, 새 저장 복원과 이전 저장 보존을 확인한다. 브라우저에서는 키보드·터치 뒤돌기, 기본 BGM 재생과 실제 신호, 일시정지·음소거, 펌프 박자 입력, 리브 게이트 선택, 320×568 조작부와 기존 다섯 음성을 함께 검사한다.

테스트 산출물은 사용자 지정 iCloud 작업 루트의 `rescene-game/arcade-music-runner-20261002/`에 보관한다. 브라우저 에뮬레이션과 오디오 신호 검사이며 실제 휴대폰 스피커 청음·재미 평가를 대신하지 않는다.

검증 결과: 단위 테스트 29개·린트·빌드 통과. 브라우저 전체 실행에서 92개 통과·데스크톱 터치 전용 1개 제외·작은 화면 3개 실패를 확인했고, 지원 버튼 줄바꿈과 화면 높이를 수정한 뒤 해당 검사 및 리브 동작 9개를 세 브라우저에서 모두 재통과했다. 기본 BGM의 실제 출력 신호(RMS), 펌프 박자 입력, 메이 뒤돌기, 기존 저장·음성 검사를 포함한다.

오디오 검사는 실제 Web Audio 시계에 가상 시계를 섞지 않도록 수정한 후 세 브라우저의 음악 검사 6개를 모두 통과했다. 최종 검토 빌드는 `build-review/`, 화면 수정 후 검사는 `browser-layout-fixed/`, 실제 시간 음악 검사는 `browser-music-realtime/`에 보관한다.

## BGM 이용 범위에 관한 답변

비영리 팬 게임이라는 이유만으로 상용 음원의 공개 웹 게임 복제·전송이 자유로워지는 것은 아니다. 비영리 공연·방송 예외의 조건은 [저작권법 제29조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025202681)에 규정돼 있다. 이번에는 사용자 선택에 따라 직접 작성한 연주 패턴을 사용했으며, 리센느 상용 음원의 사용 허락을 취득했다고 표시하지 않는다.
