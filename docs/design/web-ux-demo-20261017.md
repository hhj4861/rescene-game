# 운영 웹 사용성 확인·팬 창작 데모 — 2026-10-17

## 결과

운영 웹의 주요 플레이 흐름은 정상이다. **E2E 253개 통과·2개 조건부 제외**, 추가 화면 49조합에서 JavaScript 오류와 가로 넘침은 없었다. 실제 녹화에서도 7개 게임팩을 새 게임으로 시작해 점수·아이템·성장을 확인했다. 새로 확인한 경미한 배치 문제와 개선 후보는 아래에 분리했다.

이번 작업은 검증·영상 제작이다. 게임 코드·난이도·운영 배포는 변경하지 않았으며, 영상이나 자료를 소속사에 발송하지 않았다.

## 검증 대상·방식

- 주소: https://rescene-arcade.pages.dev/
- 검토 소스: main `610f0f8`, 게임 배포 `92b3d51`(PR #42). 문서 커밋만 다르고 게임 소스는 같다. 운영 파일 41/41개가 해당 CI 빌드와 SHA-256 일치했다.
- PC Chromium, Pixel 7 Chromium, iPhone 13 WebKit 에뮬레이션에서 11개 검사 파일 실행. `arcade`, `clean-copy`, `mobile-action-layout`, `e2e-improvements`, `mobile-video`, `pump-input`, `pump-youtube`, `game-packs`, `zena-link`, `song-audio-policy`, `carousel`.
- 확인 항목: 시작/입력/결과/재도전, 정지·이어하기, 저장 복원·팩별 기록 격리, 펌프 직접 터치·동시 입력·자동재생 차단 복구, 영상 배치, 메이 성장창·중복 방향 입력, 제나 도구·확대·음식/층 전환, 노래 중 효과음 억제.
- 253개 통과, 2개 제외, 실패 0개(4.3분). 제외는 Chromium 전용 터치 주입 검사의 다른 프로젝트 조건이다. 생략을 기능 통과로 세지 않았다.
- 추가 실제 페이지 레이아웃 49조합: 7팩 × Chromium 320×568/390×844/844×390/768×1024/1280×720 + WebKit 390×844/844×390. 새 게임 첫 화면에서 측정했다. 펌프는 오리지널 연습곡을 사용했다.
- 기존 E2E의 영상 제어 검사는 YouTube API 대역을 사용하는 항목이 있다. 데모 녹화에는 API 대역·점수/아이템 주입·게임 시간 가속을 사용하지 않았다. 저장된 게임 상태를 읽어 입력을 고르는 자동 조작이며, 실제 사람의 재미·승률·실기기 터치 감각을 검증한 것은 아니다.

- 90초 본편: 1920×1080, 30fps, H.264/AAC. 첨부용 경량본: 1280×720, 30fps.
- 0–5초 소개 → 미나미/원이/메이/제나/리브 각 11초 → 메이 보글보글·제나 십원빵 각 6초 → 모바일 10초 → 마무리 8초.
