## 회의 결과의 음악·공연 연결

사용자 추가 지시에 따라 `arrangement.js`의 버전 1 편곡기를 추가했다. 저장된 합의안과 수행 증거에서 60초 스테레오 연주곡을 재현한다. 음악 선택은 BPM/화성/선율, 안무는 타악 밀도/움직임, 승부수는 애드리브/댄스 브레이크/유닛 화음, 파트 순서는 12초마다의 중심 멤버와 음색을 바꾼다. 실제 수행 focus/quality/beatErrorMs를 프레이징/다이내믹/타이밍 및 움직임에 반영한다.

음악은 로컬 PCM으로 편곡·합성하며 외부 음악 생성 서비스를 호출하지 않는다. 브라우저 AudioContext 시계를 사용해 음원·센터 교대·안무·자막·탐색바를 동기화한다. 재생/일시정지/파트 탐색/60초 WAV 다운로드를 제공한다. 화면 이동, 탭 숨김, 상태 재렌더 시 재생을 정지하고 자원을 정리한다. reduced-motion은 동작을 줄이고 파트 표시는 유지한다.

자유문장 `direction`은 연출 문구로 표시한다. 문장 의미를 이해해 노래를 생성하거나 실제 멤버 목소리로 부르는 기능은 아니다. 심사위원은 계속 기존 수행 증거를 평가하며 음원을 들었다고 주장하지 않는다. 서버 시즌 파일에 새 파생 오디오를 쓰지 않고 기존 합의안/증거로 재생 때 재현한다. WAV는 사용자가 다운로드할 때 파일로 저장한다. 향후 편곡기 변경 시 버전별 재현성을 따로 관리해야 한다.
