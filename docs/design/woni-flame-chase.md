# 원이의 파이리 불꽃추격

2026-10-02 · 작업 브랜치 `feat/woni-flame-chase-20261002` · 운영 미반영

## 방향

사용자의 “두더지처럼만 하니 재미없다”는 피드백에 따라 구멍에서 기다리는 동작을 없애고 움직이는 파이리를 따라잡는 게임으로 바꾼다. 조작은 직접 탭 한 가지이며, 숫자 1~9는 보조 입력이다.

기존 캐릭터와 파이리 PNG, BGM, 오락기 외형은 유지한다. 민트 초원 `#d1e9da`, 잔디 `#a3c7ac`, 진한 초록 `#54896c`, 크림 `#fff8e8`, 불꽃 금색 `#e89d3b`, 먹색 `#244655`를 사용한다. 기존 Jua 제목·Noto Sans KR 설명을 유지하며, 게임 안에서는 상단 콤보/피버 → 세 높이의 추격 경로 → 하단 조작 안내 순서다. 피버만 따뜻한 불꽃색으로 전환하며 화면을 흔들거나 번쩍이지 않는다.

## 규칙과 연출

- 파이리가 좌우로 달리고 서로 다른 리듬으로 점프한다. 이동 경로와 터치 영역이 같은 좌표 계산을 사용한다.
- 초반에는 최대 두 마리, 피버/4단계 이후에는 최대 세 마리다. 경로 하나에 한 마리만 나오며 점프 중에도 터치 영역이 겹치지 않는다.
- 5연속 성공하면 6초 피버가 열린다. 피버에서는 점수가 두 배이고 출현 간격이 짧아지며, 놓쳐도 목숨을 잃지 않는다. 피버 중 추가 성공으로 시간을 무한 연장할 수 없다.
- 평소에는 도망간 파이리마다 목숨 하나를 잃고 콤보/피버 충전이 초기화된다. 금빛 파이리는 기본 점수 보너스가 있다.
- 불꽃 잔상, 점프 그림자, 잡은 위치의 점수/입자, 피버 효과음을 추가한다. 모션 줄이기 설정에서는 장식용 잔상·기울기·흐르는 배경을 생략한다. 움직이는 목표 자체는 게임 규칙으로 유지한다.
- 원이 반응은 게임 바깥 동반자 영역에 표시해 목표를 가리지 않는다. 기존 오리지널 BGM과 클리어 멤버 음성은 유지한다.

## 저장 호환

게임 ID `drive`와 기존 스테이지·목숨·최고 기록 저장 키를 유지한다. 이전 두더지형 저장의 점수·남은 시간·목숨·등장 중 파이리를 이어받고 새 피버 필드만 기본값으로 채운다. 같은 높이에 놓였던 두 파이리는 다른 경로로 배치해 겹침을 막는다. 새 저장은 피버 남은 시간, 충전, 이동 진행률, 랜덤 상태까지 그대로 재개한다.

## 검증

Node에서 이동 범위·점프·경로 분리, 5연속 피버·점수 배율·만료·목숨 보호, 단계별 속도, 기존/새 저장 호환을 확인한다. 브라우저에서는 이동하는 터치 영역, 마우스/모바일 탭, 중복 타격 방지, 일시정지/재개, 피버 저장을 확인한다. 다른 네 게임과 BGM·멤버 음성·무한 스테이지도 회귀 검증한다.

검증 산출물은 사용자 지정 iCloud 루트 `rescene-game/woni-flame-chase-20261002/`에 저장한다. Node 37개, lint, 프로덕션 빌드 통과. 전체 브라우저 검증은 124개 통과·환경별 5개 제외였으며, 마지막 저장 호환 보완 후 최종 빌드로 파이리 검증 9개를 다시 통과했다. 데스크톱 Chromium·모바일 Chromium·모바일 WebKit을 사용했고 실제 휴대폰 검증은 아니다. 데스크톱·모바일 피버 화면을 직접 확인했다. 운영 반영은 PR 머지 승인 후 진행한다.
