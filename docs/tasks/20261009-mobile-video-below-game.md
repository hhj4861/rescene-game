# 모바일 안내 팝오버와 하단 영상

- 목표: 제어부 아래 긴 설명을 터치 안내로 접고 해당 공간에서 영상을 바로 볼 수 있게 한다.
- 담당/범위: Codex 단독. main `7fbb96d`, 별도 `fix/mobile-video-below-game-20261009` worktree. 영상 게임 리브·미나미의 모바일 배치·안내만 변경. PC·곡 선택·결과 화면은 유지.
- 디자인: 잉크 #234454, 종이 #fff9e9, 민트 #92bfb3, 라일락 #c7b7dc, 하늘 #a9ccd8. Jua 제목, Noto Sans KR 설명. `[게임판/조작] → [설정 + 게임 안내 ⓘ] → [영상]`. 안내는 화면 안에서 스크롤 가능한 터치 팝오버, 본문 왼쪽 정렬, 닫기·바깥 터치·Escape 제공.
- 계획 검토: 기존 캐비닛 디자인을 유지하고 상단 영상 접기 바를 제거한다. 영상은 CSS 순서만 변경하여 iframe 재생을 다시 시작하지 않는다. 저장·곡 정보·가이드는 원래 DOM을 안내로 모아 최신 상태를 그대로 보여준다.
- 완료 기준: 320/390px 배치·팝오버 열기/닫기/키보드·가로 넘침·영상 연속 재생·PC 복귀·곡 선택/결과 회귀 검증, 실제 캡처 확인, 본인 변경 커밋·push·PR. 새 PR 머지/운영 배포는 별도 승인 대상.

- 첫 검증: 단위 191개·린트·빌드 통과. 모바일 WebKit에서 팝오버 닫기 후 트리거로 초점이 자동 복원되지 않는 차이를 확인했다. 닫기/Escape에서 직접 복원하도록 보완한다. iframe은 최초 DOM부터 게임·설정 뒤에 두어 모바일 탭 순서와 시각 순서를 맞추며 크기 변경 때 이동/재생성하지 않는다.

- 최종 검증: 전체 단위 191개, 린트·빌드, 관련 브라우저 60개 모두 통과. 초기 WebKit 초점 실패 2건을 보완한 뒤 같은 세 브라우저 전체 관련 범위를 재실행했다. 320px 화면의 제어부·팝오버 경계·200px 이상 영상·390px 복귀·PC 좌우 배치·플레이어 연속성·닫기/Escape/바깥 클릭을 확인했다.
- 시각 검토: 리브의 게임판 아래 영상, 미나미의 아래 영상과 안내 팝오버 캡처를 확인했다. 원래 폰트·색·캐비닛을 유지하고 영상을 밀어내던 긴 상시 설명을 제거했다. WebKit 닫기 초점도 확인했다. YouTube 검사는 API 대역이며 실제 외부 영상 청음을 뜻하지 않는다.
