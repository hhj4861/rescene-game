# 제나 사천성 팩과 아이콘 조작 / 메이 노래 유지

- 목표: 제나의 긴 조작 버튼을 한 줄 아이콘으로 바꾸고, 기존 십원빵과 독립 저장되는 사천성 팩 추가. 메이 강화 선택 중 아이템 노래 유지.
- 담당: 현재 Codex 세션 단독. 기준 b0b6b4e, 작업 브랜치 feat/zena-link-pack.
- UI: 기존 서체 유지, 빵 갈색 #94624d / 딸기 #e9a6b6 / 민트 #cfe6da / 짙은 녹색 #286b5c. 조작은 4등분 한 줄, SVG + 개수 배지 + 접근성 이름/툴팁. 사천성은 민트 매트 위 빵 타일과 연결선이 중심.
- 규칙: 같은 빵을 최대 2회 꺾이는 빈 경로로 연결, 바깥 경로 허용. 전부 제거하면 클리어. 1–5단계 6×6, 이후 최대 8×8, 그림 종류 증가. 힌트, 수동 섞기 2회, 막힘 시 무료 자동 섞기. 4쌍마다 노래 아이템(재생 중 중복 없음), 기존 60초 보장 정책.
- 완료 기준: 연결 규칙/생성판 완주/저장 격리 단위 검증, PC·모바일 터치/키보드/좁은 화면/완주 E2E, 메이 실제 오디오 지속 검증, lint/build. 자체 변경 커밋·push 및 PR 생성. 머지/운영은 별도 승인 전 미반영.
- 검증: lint/build 통과, 단위 테스트 228/228 통과. 관련 7개 E2E 스위트 141개 중 140개 첫 실행 통과. 나머지 1개는 앱 진입 전 page.goto(load) 시간 초과였으며 같은 빌드·입력의 desktop Chromium 집중 재검증 2/2 통과(코드 변경 없음). 총 141개 시나리오의 통과 증거 확보.
