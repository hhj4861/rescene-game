## 구현과 중간 검증

- P1-01: 키/포인터 ID별 누름 상태. 마지막 입력 해제 시 남은 방향 복구, 일시정지·성장·홈에서 초기화. 실제 Arrow/WASD/마우스 혼합 회귀.
- P1-02/03: 높이 760px 이하·폭 701px 이상은 HUD/게임판+조작. 메이 D-pad, PC 영상 왼쪽 유지. 768/844/1024 안내문 독립 행. 제나 작은 화면 내 세로 스크롤.
- P2-01: 간식 총 목표 + 각 길에 목표의 1/3(내림). 길별 수량 표시, 구 저장의 획득 간식은 균등 배분해 보존.
- P2-02: 모든 새 메이 라운드는 별빛 1/방울 0부터 성장. 스테이지 기본 공격·일반 적 체력 같은 연속 배율, 이동 속도·생성 간격은 점진 상승. 기존 저장 무기 유지.
- P2-03: 펌프 2단계는 세 박자+쉼(1단계 대비 약 1.5배 밀도). 별도 선택 버튼, 동시/반박자 예고. 50% 시작/-12% MISS 유지. chartVersion 1 저장은 원래 노트 유지.
- P2-04: 첫 아이템 이후 45초+격파 목표(12~40) 보스, 부족하면 90초에 소환. 진행 수치 표시. 노래 재생·최소 잔여 60초·추가 획득 시 카운트 유지.
- P2-05: 제나 도구를 DOM/화면 모두 판 위로. 320px에서 칸 크기를 유지하고 확대 시 48px 이상 + 내부 스크롤.
