# 멤버별 유행어 — 유튜브 출처 조사

확인일: 2026-10-01. 게임 문구를 즉시 교체하는 변경이 아니라, 실제 멤버 발언을 바탕으로 후속 연출에 사용할 출처를 수집한 기록이다.

## 확인 방법과 확실성

YouTube 공개 검색과 영상 메타데이터·한국어 자동 자막을 확인했다. 핵심 출처는 MBCentertainment의 2026-08-07 업로드 영상이다. 방송일은 2026-08-08이며, 약 02:09부터 진행자가 멤버들의 유행어 소개를 요청한다.

[공식 유튜브: 전참시 멤버별 유행어 소개](https://www.youtube.com/watch?v=pWTBJV0OrqU&t=129s)

아래 시점은 자동 자막의 발화 시작 시점이다. 자막에는 ‘거제→커제’, ‘오이쉬에→어이시’, ‘그립감→그릴까’ 같은 오인식이 있다. **시점과 발언 내용의 근거이며 정확한 발음·억양·표정·손동작을 프레임 단위로 검수했다는 뜻은 아니다.** 직접 청음·포즈 검수 완료로 표시하지 않는다.

제나의 별도 후보 **‘아니~!’**는 실패·아슬아슬한 판정에 더 어울린다. 팬 자료와 여러 클립 제목에서 반복 사용을 확인했지만, 이번 조사에서는 해당 표현의 정확한 원본 발화 시점을 확보하지 못했다. 위 공식 소개의 긍정 문구와 같은 검증 수준으로 다루지 않는다.

## 후속 반영 기준

1. 원문, 방송에서 바꿔 말한 변형, 게임용 새 문장을 구분한다. 유행어 수집과 실제 멤버 음성 파일 확보는 별개다.
2. 원이·미나미는 짧은 성공 감탄, 리브는 주고받는 반응, 제나는 실패 반응과 긍정 클리어 반응을 분리하는 구성이 자연스럽다. 이는 게임 연출 제안이다.
3. 실제 포즈는 위 구간의 영상·억양을 함께 확인한 뒤 확정한다. 현재 게임의 윙크·손하트·브이 포즈를 실제 공식 시그니처라고 단정하지 않는다.

조사 자막은 iCloud 작업 산출물의 `rescene-game/arcade-progression-merge-20261001/research/`에 보관했다. Git에는 자막 전문이나 영상·음성을 포함하지 않았다. 게임은 이번에 머지한 PR #9의 임시 창작 문구·합성 음성 상태를 유지한다.

## 후속 구현 — 2026-10-01

사용자 요청으로 수집 문구와 실제 발언 클립을 게임에 연결했다. 원본 화면 자막을 추가 확인했으며 메이·제나의 게임용 각색은 녹음 원문과 분리해 표시한다. 구현 구간·파일·재생 정책·검수 한계는 [멤버 음성 연결](../design/member-voices.md)에 기록했다. 후속 사용자 승인으로 PR #10을 머지하고 운영 반영했다. 배포 소스와 확인 결과는 [배포 기록](../deployment/arcade-pages.md)을 따른다.
